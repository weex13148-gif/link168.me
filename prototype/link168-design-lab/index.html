Visual Directions

三套设计方向总览

A

温润品牌编辑部

给创作者、咨询师、小品牌的内容型名片。强调留白、标题、故事、作品和商务合作。

  • 适合公开主页传播
  • 适合小红书/公众号截图
  • 后台效率需要 B 补足

B

现代创作者工作台

给后台和核心编辑流程。强调任务、状态、组件管理、实时预览和低学习成本。

  • 最适合主 Dashboard
  • 统一当前 Dashboard / Workbench
  • 需要 A 的温度避免工具感

C

AI 经营中枢

给付费 AI、经营版和企业版。强调知识库、线索、任务、智能建议和可信数据。

  • 适合高价值付费能力
  • 适合企业版销售
  • 不适合免费首屏过早使用

Flows

Recommendation

推荐方向

推荐混合方案：B 为骨架，A 做气质，C 做付费能力。

用现代创作者工作台统一 Dashboard 与 Workbench；公开主页吸收温润品牌编辑部的内容气质；AI 经营中枢只进入 Plus、经营版和企业版，避免免费用户第一屏过重。
