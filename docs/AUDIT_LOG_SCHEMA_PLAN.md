# Link168 日志与 IP 方案规划

## 1. 访问日志

记录公开主页访问事件，包括主页 ID、用户 ID、访问时间、来源、设备、地区、IP、User-Agent。普通用户仅展示聚合地区和趋势。

## 2. 登录日志

记录登录成功、登录失败、退出登录、异常登录事件，包括用户 ID、邮箱、IP、地区、设备、时间和结果。

## 3. 链接点击日志

记录用户公开主页中每条链接的点击事件，包括链接 ID、主页 ID、访问者 IP、设备、来源、地区、点击时间。

## 4. 操作日志

记录管理员和超级管理员操作，包括冻结、封禁、解冻、删除举报、查看 IP、修改角色、处理违规内容等。

## 5. IP 权限隔离

- 普通用户：只看地区、设备、来源等聚合信息。
- 普通管理员：admin 默认不能看完整 IP。
- 超级管理员：super_admin 可在风控场景查看完整 IP。
- 查看完整 IP 必须写入操作日志。

## 6. 90 天详细 IP 留存

详细 IP 数据建议保留 90 天，用于安全排查、风险识别和依法协查。超过 90 天后进入脱敏或删除流程。

## 7. 安全审计日志不少于 6 个月

管理员操作日志、超级管理员查看 IP 日志、封禁冻结日志应至少保留 6 个月，便于追溯平台安全操作。

## 8. 90 天后 IP 脱敏或删除

90 天后访问 IP、点击 IP、登录 IP 可执行脱敏处理，例如保留城市级地区，不再保留完整 IP。确需长期保留的事件应进入合规审计白名单。

## 9. 普通用户只展示地区

普通用户数据页只展示地区分析、访问趋势、设备来源、链接点击排行，不展示访问者完整 IP 或登录者完整 IP。

## 10. 超级管理员查看 IP 也要记录操作日志

超级管理员查看 IP 时必须记录操作日志，字段建议包括：操作人 ID、目标用户 ID、日志类型、查看原因、查看时间、查看 IP 范围、请求来源 IP。

## 11. 建议数据表

后续可新增以下表，本轮只做文档规划，不实施数据库变更：

- `page_visit_logs`
- `link_click_logs`
- `login_logs`
- `admin_action_logs`
- `ip_retention_jobs`

## 12. 合规边界

IP 属于敏感信息，展示和查询应遵循最小权限原则。普通用户只看经营分析结果，超级管理员仅在风控、违规处理、依法协查场景查看完整 IP。
