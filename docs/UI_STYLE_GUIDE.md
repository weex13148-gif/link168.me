# Link168.me UI Style Guide

> 本文档基于当前指定视觉参考主图提炼，用于指导 link168.me 后续 UI 统一整改。
> 本文档只定义视觉方向和页面规范，不涉及业务代码、数据库、接口、部署或支付逻辑。

## 1. 总体视觉方向

### 设计定位

link168.me 的主视觉方向应定义为：

**温柔生活感 + 轻商业感 + 中文自媒体审美 + 手机优先的数字名片工具。**

它不是程序员后台工具，也不是廉价模板站。整体应让用户第一眼感觉：

- 可信
- 温暖
- 简单
- 适合分享
- 适合自媒体人、商家、个人 IP 使用
- 能把链接、二维码、个人主页做得像一张精致名片

### 核心气质

- 背景像自然光下的暖白纸张或织物。
- 品牌色使用草木绿，不要大面积深绿。
- 金色、橙色、陶土色只作为轻点缀。
- 卡片像摆在桌面上的产品模块，有轻微阴影和柔和圆角。
- 手机预览是全站视觉中心，比例必须统一。
- 二维码分享卡片要像可转发的品牌物料，不像技术弹窗。

## 2. 颜色规范

### 主背景色

| 用途 | 建议颜色 | 说明 |
| --- | --- | --- |
| 页面主背景 | `#F7F1E7` | 暖米白，接近参考图底色 |
| 卡片背景 | `#FFFDF8` | 接近白色，但不要纯白刺眼 |
| 次级背景 | `#F2E7D8` | 用于浅色模块、手机内部块 |
| 分隔背景 | `#E8DCCB` | 极轻分割线、边框 |

### 品牌色

| 用途 | 建议颜色 | 说明 |
| --- | --- | --- |
| 主品牌绿 | `#6F8F4E` | 按钮、选中态、核心图标 |
| 深文字绿 | `#3F5F31` | 标题小强调、状态文字 |
| 浅草木绿 | `#DDE8CD` | 标签、icon 背景、选中底色 |
| hover 绿 | `#5E7F3F` | 主按钮 hover |

### 辅助色

| 用途 | 建议颜色 | 说明 |
| --- | --- | --- |
| 陶土橙 | `#C9824B` | 商品、强调 icon |
| 暖金色 | `#C8A45D` | 会员、重点 CTA、小装饰 |
| 柔和红 | `#D9654F` | 小红书类平台图标 |
| 微信绿 | `#5AA94F` | 微信相关入口 |
| 墨黑 | `#2B241E` | 主标题、正文主色 |
| 次级文字 | `#7A6D5E` | 说明文字 |
| 弱文字 | `#A69A8A` | footer、placeholder |

### 禁止用法

- 禁止大面积使用深绿铺满页面。
- 禁止纯白背景 + 高饱和绿按钮的生硬组合。
- 禁止金色大面积使用，避免廉价会员感。
- 禁止所有模块都是同一种绿色。
- 禁止背景过暗，除非是独立 VIP 主题。

## 3. 字体与层级

### 字体族

全站建议统一：

```text
Inter,
system-ui,
-apple-system,
BlinkMacSystemFont,
"Segoe UI",
"PingFang SC",
"Hiragino Sans GB",
"Microsoft YaHei",
"Noto Sans CJK SC",
"Noto Sans CJK JP",
sans-serif
```

### 字体层级

| 场景 | 桌面端 | 移动端 | 字重 | 说明 |
| --- | --- | --- | --- | --- |
| 首页 Hero 主标题 | 52-64px | 34-42px | 600-700 | 必须明显大于所有模块标题 |
| 首页副标题 | 26-34px | 22-28px | 500-600 | 可带一点手写感或柔和字距 |
| 页面标题 | 28-36px | 24-30px | 600 | 注册、登录、帮助、举报 |
| 模块标题 | 20-24px | 18-22px | 600 | 卡片、后台区域 |
| 卡片标题 | 15-18px | 15-17px | 600 | 链接卡、入口卡 |
| 正文说明 | 14-16px | 14-15px | 400-500 | 保证中文阅读舒服 |
| 辅助说明 | 12-13px | 12-13px | 400 | 不要低于 12px |
| 按钮文字 | 14-16px | 14-16px | 600 | 主按钮要清楚 |

### 文案视觉规则

- 中文标题不要全都一样大。
- 首页主标题必须最大。
- Dashboard 里的标签、按钮、输入框字号要统一。
- 法律页正文可以更克制，但标题仍要清楚。
- 手机预览内部文字不能过小，最小 12px。

## 4. Logo 与品牌标识

### Logo 风格

参考图中 Logo 是轻量叶子图标 + Link168.me 文本，整体很轻。

要求：

- Logo 不要像贴纸一样大。
- 首页左上 Logo 可以比后台稍大，但仍要轻。
- Dashboard 里 Logo 应更像导航标识，不抢制作区注意力。
- 手机底部 Powered by Link168 使用小字，不要大卡片。

### Powered by Link168

公开主页底部建议：

```text
Powered by Link168
```

规范：

- 字号 11-12px。
- 颜色使用 `#A69A8A`。
- 可以带一个 12-14px 小叶子图标。
- 不要使用大 Logo 卡片。
- 不要像广告贴片。

## 5. 按钮规范

### 主按钮

用于：首页注册、发布、保存、创建、分享。

视觉：

- 背景：`#6F8F4E`
- hover：`#5E7F3F`
- 文字：`#FFFFFF`
- 高度：桌面 44-48px，移动端不低于 44px
- 圆角：16-22px，偏胶囊但不要过度
- 阴影：轻微草木绿阴影

示例文案：

- 免费创建我的页面
- 免费创建我的 Link168
- 发布
- 保存资料
- 分享主页

### 次按钮

用于：查看模板、帮助中心、预览主页。

视觉：

- 背景：`#FFFDF8`
- 边框：`#D9CBB8`
- 文字：`#3F5F31` 或 `#2B241E`
- hover：浅米色背景

### 图标按钮

用于编辑、删除、复制、分享、开关。

规范：

- 导航图标：18px
- 普通功能图标：22-24px
- 卡片主图标：28-32px
- 数据图标：24px
- 手机预览链接图标：20-24px
- 同类图标尺寸必须一致

### 禁止用法

- 禁止白色空按钮没有文字。
- 禁止按钮高度忽大忽小。
- 禁止主按钮和次按钮视觉权重混乱。
- 禁止所有按钮都用同一种绿色。

## 6. 卡片规范

### 基础卡片

参考图中的卡片像温暖桌面上的纸片。

视觉：

- 背景：`#FFFDF8`
- 圆角：18-24px
- 边框：`1px solid rgba(139, 117, 92, 0.16)`
- 阴影：`0 18px 45px rgba(86, 68, 46, 0.12)`
- 内边距：20-28px

### 小卡片

用于链接列表、帮助入口、功能入口。

- 圆角：14-18px
- 内边距：12-16px
- icon 背景使用浅草木绿、浅陶土、浅米色
- hover 时上浮 2-4px

### 数据卡片

用于访问量、点击量、转化率。

- 数字必须明显，字号 24-32px。
- 趋势用小绿箭头或简短百分比。
- 图表线条使用草木绿。
- 背景不要像金融后台，应保持轻生活感。

## 7. 首页布局规范

### 首页整体结构

首页应参考主图左侧区域：

1. 左上轻量 Logo
2. 大标题
3. 简短说明
4. 平台/场景入口 icon
5. 主 CTA + 次 CTA
6. 右侧或中部展示 Dashboard + 手机 + 分享卡视觉

### Hero 标题

标题方向可以参考：

```text
用一个链接
连接你的热爱与生活
```

也可以结合现有品牌语：

```text
一个链接
连接你的内容、服务与生意
```

要求：

- 标题必须大。
- 行距要松。
- 不要像后台说明文字。
- 不要使用生硬科技风标题。

### 首页背景

- 使用暖白、米白、自然光阴影。
- 可加入轻微花草、叶子、纸张、柔和光斑。
- 装饰只做氛围，不要抢 UI。

### 首页功能入口

参考图中五个入口：

- 我的小店入口
- 预约咨询
- 商品橱窗
- 微信客服
- 社媒合集

这些入口应以 icon + 短文字展示，icon 背景统一为浅色块。

## 8. 注册 / 登录页规范

### 登录卡片

参考图左下登录卡片：

- 卡片居中或左侧偏中。
- 背景为暖白。
- 输入框高度不低于 44px。
- 输入框边框轻，不要厚重。
- 登录/注册 Tab 用绿色下划线表达当前状态。
- 主按钮使用草木绿。

### 注册页

注册页应比登录页更强调“抢占主页地址”：

1. link168.me/ 后缀输入
2. 邮箱
3. 密码
4. 确认密码
5. 协议勾选
6. 注册按钮

视觉上不要左白右绿硬切割，应使用同一套暖白背景与手机预览。

### 忘记密码页

- 使用同样卡片风格。
- 文案要简短。
- 不要做复杂客服后台感。

## 9. Dashboard 后台布局规范

### 总体方向

Dashboard 应像“数字名片制作器”，不是程序员管理后台。

参考图中后台特点：

- 顶部浏览器式容器
- 左侧轻导航
- 中间编辑区
- 右侧模块/外观/设置面板
- 手机预览作为视觉焦点

### 顶部导航

建议结构：

- 左侧：Link168.me Logo
- 中间：制作 / 外观 / 数据 / 我的
- 右侧：预览 / 发布 / 分享

规范：

- 导航字号 15-16px。
- 字重 600。
- 不要巨大胶囊导航。
- 选中态使用浅草木绿底色或绿色下划线。

### 左侧导航

可参考图中：

- 我的主页
- 内容管理
- 链接管理
- 预约管理
- 商品管理
- 数据统计
- 表单与留言
- 团队协作
- 设置中心

V0.1 不一定全部真实开放，但视觉上可以作为后台结构参考。

### 制作区

应包含：

- 主页资料卡
- 链接管理卡
- 模块添加区
- 保存/发布按钮

资料卡视觉：

- 头像居中或左侧
- 昵称大于简介
- 平台 icon 一排
- 编辑按钮放底部或右上

### 链接管理区

参考图下方链接管理卡：

- 每条链接一行
- 左侧 icon
- 中间标题 + URL
- 右侧编辑 / 删除 / 开关
- 行高充足，不要拥挤
- 开关使用绿色打开态

### 数据区

参考图中的数据概览：

- 三个核心数据卡
- 一张趋势图
- 时间筛选在右上
- 空数据时也要有完整框架

## 10. 公开主页布局规范

### 手机 mockup

全站手机 mockup 必须统一：

- 比例接近 390:844。
- 圆角一致。
- 边框和阴影一致。
- 不能首页一个比例、Dashboard 一个比例、主题卡又一个比例。

### 公开主页结构

参考图手机内页面：

1. 顶部返回/分享小图标
2. 头像
3. 昵称
4. 分类标签或简介
5. 一句话介绍
6. 平台 icon
7. 链接卡片列表
8. 分享名片 / 保存到手机按钮
9. Powered by Link168

### 链接卡片

每条链接建议：

- 左侧：标题 + 简述
- 右侧：图片或 icon
- 卡片背景：暖白
- 圆角：14-18px
- 间距：10-12px

适合展示：

- 我的小店入口
- 预约咨询
- 商品橱窗
- 微信客服
- 我的作品集

### 公开主页底部

- Powered by Link168 放最底部。
- 不要放中间。
- 不要用大广告卡。

## 11. 二维码分享卡片规范

### 卡片结构

参考图右上分享卡：

1. 标题：分享你的页面
2. 说明：扫码访问我的链接主页
3. 二维码
4. 主页地址
5. 快捷操作

快捷操作建议：

- 微信
- 朋友圈
- 复制链接
- 保存图片

### 二维码视觉

- 二维码放在白色或暖白色容器内。
- 中间可放 Link168 小叶子 Logo。
- 二维码周围留白充足。
- 不要使用花哨边框影响扫码。

### 分享卡尺寸

- 桌面弹窗：宽 360-420px。
- 移动端：宽度占屏幕 90%左右。
- 内容居中。
- 按钮触控区域不低于 44px。

## 12. 帮助 / 法律 / 举报页面规范

### 帮助中心

参考图右侧帮助中心卡：

- 标题简洁。
- 问题列表用箭头。
- 底部提供“查看更多帮助”按钮。
- 可加入小花瓶/叶子装饰，但要轻。

### 法律页面

参考图右下服务条款卡：

- 卡片化展示。
- 链接清晰。
- 底部公司与备案信息清楚。
- 不要做成长篇黑字白底的临时文档感。

### 举报中心

应保持可信和正式：

- 使用同一暖白卡片系统。
- 表单字段清晰。
- 提交按钮使用主品牌绿。
- 不要营销化。

## 13. 管理员举报后台规范

管理员后台可以更密集，但仍应延续品牌：

- 背景用暖灰白。
- 表格卡片白底。
- 状态标签使用柔和色。
- 高风险状态可用陶土红，不要刺眼大红。
- 操作按钮保持 36-40px 高。
- 不要做成黑色技术后台。

## 14. 移动端规范

### 基础尺寸

- 主按钮高度不低于 44px。
- 输入框高度不低于 44px。
- 页面左右安全边距 16-20px。
- 卡片间距 12-16px。
- 手机端标题不要小于 24px。

### 移动端布局

- 首页：标题、说明、CTA、输入框优先，视觉图下移。
- 注册/登录：卡片宽度 100%，不要过窄。
- Dashboard：手机预览可以折叠或置顶，避免横向溢出。
- 分享弹窗：底部弹层或居中卡片均可，但宽度不能超过屏幕。
- 公开主页：保持单列，所有按钮可点击区域充足。

### 禁止问题

- 禁止移动端横向滚动。
- 禁止按钮文字被截断。
- 禁止二维码过小。
- 禁止手机 mockup 被压扁。

## 15. 装饰元素规范

可用元素：

- 叶子
- 小花
- 花瓶
- 柔和织物纹理
- 纸张质感
- 手绘细线心形
- 浅色自然光斑

使用原则：

- 装饰只做氛围。
- 装饰不能影响内容阅读。
- 同一屏装饰不要超过 2-3 处。
- Dashboard 内装饰要更少，避免影响效率。

## 16. 页面落地优先级

### 第一优先级

1. 首页
2. 注册页
3. Dashboard 制作页
4. 公开主页

原因：

- 首页决定第一印象。
- 注册页决定转化。
- Dashboard 决定用户能不能完成主页。
- 公开主页决定用户愿不愿意分享。

### 第二优先级

1. 登录页
2. 忘记密码页
3. 二维码分享弹窗
4. Dashboard 数据页
5. Dashboard 外观页

### 第三优先级

1. 帮助中心
2. 举报中心
3. 用户协议
4. 隐私政策
5. 管理员举报后台

## 18. 总结

link168.me 的主视觉不应继续往“纯 SaaS 后台”或“大面积绿金模板”方向走。

最适合的方向是：

**暖白自然场景 + 草木绿品牌色 + 精致卡片 + 统一手机 mockup + 轻量二维码分享卡。**

这套风格能同时服务：

- 自媒体人
- 小店主
- 咨询顾问
- 内容创作者
- 本地生活商家
- 个人 IP

上线第一版应优先保证：

1. 首页看起来可信、温暖、好用。
2. 注册流程看起来简单、不压迫。
3. Dashboard 像制作器，不像后台表格。
4. 公开主页适合直接分享。
5. 二维码卡片有品牌感，能用于微信传播。
