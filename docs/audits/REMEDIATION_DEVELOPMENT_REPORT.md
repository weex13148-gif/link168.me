## 3. 用户后台五分类整改

### 3.1 正式一级分类

用户后台永久只保留：

1. 首页
2. 名片
3. 客户
4. AI
5. 我的

手机版中固定显示在屏幕底部。

桌面端可以改为左侧栏或顶部栏，但不能改变五个分类、顺序和职责。

### 3.2 组件化原则

以下功能不再占一级导航：

- 产品和服务
- 模板和主题
- 二维码和短链
- 数据分析
- 知识库
- AI加量包

- 企业空间
- 通知、安全和设置

它们必须作为五个分类中的组件卡片、快捷入口或二级页面出现。

- 来源渠道

## 4. 企业空间与角色页面整改

### 4.1 企业入口

企业客户登录后：

```text
底部“我的”
→ 企业空间组件
→ /console/enterprise
→ 按当前企业角色进入对应页面
```

- 企业所有者或管理员 → `/console/enterprise/admin`
- 普通企业成员 → `/console/enterprise/member`
- 同时属于多个企业 → 先选择企业空间，再判断该空间中的角色

不增加“企业”第六个底部分类。

### 4.2 正确的权限关系

企业管理员和企业成员不是两个完全隔离的系统。

正确关系：

```text
企业管理员权限
= 企业成员基础权限
+ 企业管理权限
```

管理员本身也是企业成员，可以完成成员工作，同时管理企业成员和企业级资源。

严格隔离发生在不同Workspace之间：

```text
企业A数据 ≠ 企业B数据
```

企业内部再按角色、部门、资源归属和授权范围控制访问。

### 4.3 企业管理员页

正式路径：`/console/enterprise/admin`

需要开发的组件：

- 企业主页配置
- 企业Logo、品牌色、简介和联系方式
- 企业产品库
- 企业知识库
- 企业客户池
- 成员列表
- 邀请、移除和冻结成员
- 成员角色和权限
- 成员名片管理
- 客户线索分配
- AI共享额度和成员额度分配
- AI加量包购买
- 企业域名
- 团队报表
- 操作日志
- 套餐、成员扩展、订单和发票
- 管理员本人的工作任务

管理员不得查看：

- 成员密码
- 成员私人会话
- 成员个人账号安全信息
- 不属于企业的私人工作区数据
- 其他企业数据

### 4.4 企业成员页

正式路径：`/console/enterprise/member`

需要开发的组件：

- 我的企业成员名片
- 企业品牌规范
- 分配给我的产品和资料
- 分配给我的知识库
- 分配给我的客户线索
- 我的跟进任务
- 我的企业AI额度和使用记录
- 企业公告
- 我的工作数据
- 联系企业管理员

成员页不得显示：

- 成员管理
- 企业全局权限
- 企业套餐和账单
- 域名配置
- 全企业审计日志
- 未授权客户、知识库和部门数据

### 4.5 企业主页规则

- 企业管理员配置企业官方主页。
- 企业成员配置自己的成员名片。
- 成员名片必须遵守管理员配置的企业品牌和权限规则。
- 企业主页和成员名片共享企业产品、知识库和品牌资产，但展示范围由权限决定。

### 4.6 移动端规则

企业管理员页和成员页仍位于“我的”内部。

进入企业空间后可以使用页面顶部返回、企业切换器、页面内部标签或组件卡片，但不得再叠加一套与主底部导航冲突的五栏导航。

## 7. AI加量包成本保护

内部保护线：

```text
每1,000 AI点对应的模型官方原价成本预算不高于¥1
```

标准文本任务按约120点估算，实际按模型、Token、思考、知识库、工具和图片能力动态扣点。

不使用限时折扣、免费额度或新客优惠作为长期成本基础。

上线后每月按真实模型账单、退款、支付手续费、税务和服务器成本复盘。

## 8. 正式验收要求

### 五分类用户后台

- 手机底部只显示首页、名片、客户、AI、我的。
- 不存在第六个一级入口或横向滚动导航。
- 所有其他功能都进入组件或二级页面。
- 免费、个人会员和企业用户使用相同五分类结构。

### 企业入口和角色

- 企业客户只能从“我的”中的企业空间组件进入。
- 管理员默认进入管理员页，普通成员进入成员页。
- 管理员可以管理本企业成员并完成成员基础工作。
- 普通成员不能访问成员管理、企业账单和全局设置。
- 不同企业之间无法互相访问数据。
- 管理员不能查看成员密码、私人会话和非企业私人数据。
- 多企业用户可以选择企业，并按所选企业中的角色进入页面。

### AI和推广

- 免费用户前端和API均不能购买AI加量包。
- 点数批次90天有效并按最早到期优先消耗。
- AI失败返回原额度来源和原批次。
- 佣金30天内不可提现。
- 上月满足条件佣金次月15日结算。
- 不足¥50自动累计。

### 主业务闭环

- 名片创建、预览、发布和公开访问正常。
- 访客真实留资，用户可查看和跟进。
- 支付宝、订单、会员、AI和退款可追踪。
- 360–430px无横向溢出。
- 最终验收时lint、typecheck和生产构建通过。
