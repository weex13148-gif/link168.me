## 4. 首页经营总览整改

### 4.1 正式定位

首页不是功能入口大全，而是：

> 名片经营状态、客户变化和下一步行动的统一总览页。

用户首屏必须快速知道：

1. 名片是否正常发布。
2. 最近是否有新客户。
3. 现在最该完成什么动作。

正式路径：`/console`

### P0-HOME-1 顶部身份栏

**状态：待开发/待统一**

显示头像、名称、会员等级、通知、企业身份和重要账号状态。

要求：

- 不放复杂功能菜单。
- 邮箱未验证、会员到期、账号受限等状态必须真实。
- 企业用户显示当前企业或企业身份。

### P0-HOME-2 名片状态主卡片

**状态：待开发/可复用现有名片数据**

显示：

- 名片缩略预览。
- 名片名称。
- 未创建、草稿、已发布、已下线或被冻结状态。
- 公开地址。
- 最近更新时间。
- 待完善项目。

操作最多三个：预览、编辑、分享二维码。

规则：

- 首页首屏只保留一个最高视觉层级主按钮。
- 新用户主按钮为创建名片。
- 未完成用户主按钮为继续完善。
- 已发布用户主按钮为分享名片。
- 冻结或下线时显示原因和恢复动作。

### P0-HOME-3 四项经营数据

**状态：有数据模型基础，待聚合接口与页面**

显示：

| 指标 | 数据来源方向 |
|---|---|
| 访问人数 | ProfileVisit或统一访问统计 |
| 新增客户 | Lead真实数据 |
| 联系点击 | LinkClick或联系组件点击 |
| 转化率 | 有效留资或咨询数 ÷ 访问数 |

要求：

- 默认显示今日数据和本周趋势。
- 时间口径保持一致。
- 无数据时不显示虚假示例数值。
- 点击进入`/console/analytics`。
- 接口失败显示重试状态，不能将错误显示为零。

### P0-HOME-4 今日待办

**状态：待开发**

待办根据真实状态自动生成，来源包括：

- 新客户待联系。
- 到期跟进任务。
- 名片未发布或资料不完整。
- 产品缺少关键内容。
- 企业成员名片待完善。
- 企业分配的新客户或任务。
- AI点数即将到期。
- 邮箱未验证。
- 会员即将到期。
- 推广佣金达到提现条件。

完成后自动消失，暂不建设复杂项目管理系统。

### P0-HOME-5 最近客户

**状态：有Lead基础，待首页组件**

显示最近3至5条真实线索：

- 客户名称或脱敏联系方式。
- 感兴趣产品。
- 来源渠道。
- 当前状态。
- 提交时间。

提供联系、跟进、修改状态和查看详情。

无线索时显示“分享名片，让第一位客户找到你”，并提供分享按钮，不显示空白表格。

### P0-HOME-6 快捷操作

**状态：待开发**

手机版最多四个：

1. 编辑名片。
2. 分享二维码。
3. 添加产品。
4. 记录客户跟进。

企业角色可替换一个入口：

- 管理员：成员管理或企业主页。
- 成员：企业任务或成员名片。

不得扩展为密集功能宫格。

### P0-HOME-7 AI经营建议

**状态：待开发**

根据真实访问、产品和客户数据提供一条可执行建议。

规则：

- 建议必须附带数据依据摘要。
- 付费用户可进入相应Agent并携带上下文。
- 免费用户只看到AI权益说明和升级入口，不产生真实AI调用。
- 数据不足时使用基础规则提醒，不伪造AI经营结论。

### P0-HOME-8 产品与内容状态

**状态：待开发**

显示：

- 上架产品数。
- 未完善产品数。
- 热门产品。
- 缺少封面、介绍或行动按钮的产品。
- 名片核心组件完整度。

只展示状态和行动入口，不在首页放完整产品表格。

### P0-HOME-9 角色专属组件

**状态：待开发**

推广员显示：锁定佣金、可提现佣金、下次结算日、推广访问和成交。

企业成员显示：当前企业、公告、分配客户、企业AI额度、企业任务和成员名片状态。

企业管理员显示：企业主页状态、成员数量、待处理事项、新增客户、团队跟进和AI额度预警。

首页只显示摘要，完整管理仍进入对应二级页面。

### 4.2 首页移动端顺序

```text
顶部身份栏
→ 名片状态主卡片
→ 四项经营数据
→ 今日待办
→ 最近客户
→ 快捷操作
→ AI经营建议
→ 产品与内容状态
→ 角色专属组件
```

首屏优先级不能改变：

1. 名片状态。
2. 新客户或经营数据。
3. 最重要待办。

### 4.3 首页空状态

- 新用户：创建名片、添加产品、分享名片三步引导。
- 无访问：提示分享名片。
- 无客户：引导获取第一位客户。
- 接口失败：显示重试，不冒充零数据。
- 账号冻结：显示原因和申诉入口。
- 会员到期：保留基础经营能力，按规则限制付费权益。

## 5. AI分类组件整改

正式结构：

```text
AI额度总览
+ 六大AI Agent
+ 访客AI接待
+ 知识库
+ AI任务记录
+ AI使用与消耗
+ AI加量包
+ 企业共享AI额度
```

### P0-AI-1 AI额度总览

显示会员、套餐额度、加量包点数、最近到期批次、本月使用量和企业额度状态。

### P0-AI-2 六大Agent卡片

手机端两列显示六大Agent，每张卡片显示用途、最近任务、权限状态和进入按钮。

### P0-AI-3 访客AI接待

包括欢迎语、推荐问题、业务范围、知识库、留资引导和接待记录。有效咨询必须写入客户线索。

### P0-AI-4 知识库

统一个人与企业知识库权限，企业成员只能使用授权资料。

### P0-AI-5 AI任务记录

保存任务标题、Agent、类型、时间、状态、点数和继续编辑、复制、导出、归档操作。

### P0-AI-6 AI使用与消耗

区分套餐、购买和企业共享额度，并记录成功、失败和回补。

### P0-AI-7 AI加量包

路径：`/console/ai-packs`，显示五档套餐、支付、90天批次和到期提醒。

### P0-AI-8 企业共享AI额度

成员查看本人额度；管理员管理企业总额度、成员分配、预警和购买。

手机首屏优先：额度、六大Agent、访客AI接待。

## 6. 企业空间与角色页面

企业客户从“我的”进入企业空间：

- 管理员进入`/console/enterprise/admin`
- 普通成员进入`/console/enterprise/member`
- 多企业用户先选择企业空间

企业管理员权限等于企业成员基础权限加企业管理权限。

严格隔离对象是不同企业空间；企业内部按照角色和资源授权。

## 9. 验收标准

### 首页

- 新用户首页突出创建名片，不展示虚假数字。
- 已发布用户首屏看到名片状态、客户数据和最重要待办。
- 名片卡根据状态切换主按钮。
- 四项数据来自真实数据库且时间口径一致。
- 待办根据真实状态生成并自动消失。
- 最近客户支持快捷跟进。
- 快捷操作最多四个。
- AI建议具有真实数据依据，免费用户不产生真实调用。
- 角色专属组件只向对应用户显示。
- 接口失败显示重试，不显示伪造零数据。

### 五分类和AI

- 手机底部只显示首页、名片、客户、AI、我的。
- 所有其他功能进入组件或二级页面。
- AI额度、Agent权限和任务记录真实。
- AI接待产生的有效咨询进入客户线索。
- 企业成员只看本人AI额度，管理员管理共享额度。

### 企业和商业闭环

- 企业管理员和成员角色分流正确。
- 不同企业不能互相访问数据。
- 免费用户不能购买AI加量包。
- 点数批次90天有效并按最早到期消耗。
- 佣金30天内不可提现，次月15日结算，不足¥50累计。
- 名片、留资、支付、会员、AI和退款可追踪。
- 360–430px无横向溢出。
