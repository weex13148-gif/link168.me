## 2. 当前产品基准

Link168正式定位为：

> AI SaaS经营名片工具与商业基础设施平台。

长期产品连接：

```text
微信身份
+ 经营名片
+ 客户线索
+ 六大AI Agent
+ 企业自购域名
+ 企业微信、飞书、钉钉
```

五档会员：免费版、Plus、Pro、企业版、企业Pro。

AI加量包仅向付费套餐开放，每个点数批次独立90天。

## 3. 五分类用户后台

1. 首页
2. 名片

## 4. 统一身份与微信登录整改

### P0-ID-1 内部User ID

**状态：待统一**

目标：内部不可变`User ID`成为唯一账号主键。

邮箱、普通微信、企业微信、飞书和钉钉作为外部身份绑定，不直接承担会员、订单、AI、名片和企业权限主键职责。

需要检查：

- 当前User模型是否允许无邮箱账号。
- 当前email字段是否强制唯一且不可为空。
- Session、Order、Subscription、AI账户和WorkspaceMember是否统一关联User ID。
- 当前注册流程是否默认依赖邮箱和密码。

### P0-ID-2 微信直接注册

**老板已批准：方案A。状态：待开发**

流程：

```text
微信授权
→ 服务端校验身份
→ 查询绑定关系
→ 未绑定则创建User ID和个人空间
→ 建立微信身份绑定
→ 完成登录
```

要求：

- 不要求用户先填写邮箱。
- 重复授权不能创建重复账号。
- 授权失败不能遗留半成品正式账号。
- 微信昵称和头像仅作为初始资料。
- 微信身份标识不得暴露到前端或公开日志。

### P0-ID-3 已登录用户绑定微信

**老板已批准。状态：待开发**

入口：

```text
我的
→ 账号安全/身份绑定
→ 绑定微信
```

要求：

- 在已登录会话中发起。
- 微信未被占用时绑定当前User ID。
- 微信已绑定其他账号时停止，不覆盖、不自动合并。
- 绑定、解绑和冲突记录安全日志。

### P0-ID-4 邮箱规则修正

**状态：待整改**

- 微信直接注册且未填写邮箱的账号不适用30天邮箱冻结。
- 邮箱注册用户仍需在30天内完成邮箱验证。
- 后续绑定邮箱在验证成功前不能作为已验证找回凭证。
- 高风险操作可要求已验证邮箱或中国大陆手机号，具体组合待决定。

### P0-ID-5 身份冲突与合并

**状态：规则未批准，开发时只做冲突拦截**

当前不得：

- 自动合并已有账号。
- 根据昵称、头像、手机号或企业成员信息推测合并。
- 覆盖已经存在的外部身份绑定。

待老板决定安全合并、资产迁移和主账号保留规则。

## 5. 企业通讯录与待激活成员整改

### P0-ENT-ID-1 企业连接基础模型

**状态：待开发**

需要统一企业协作连接层，支持：

- 企业微信连接器
- 飞书连接器
- 钉钉连接器

统一处理：

- 外部企业与Workspace绑定
- 外部部门映射
- 外部成员映射
- 授权状态和同步游标
- 回调验签、幂等、重试和审计

不得把三个平台的差异散落到名片、客户和AI模块中。

### P0-ENT-ID-2 通讯录同步

**老板已批准。状态：待开发**

正式流程：

```text
同步企业通讯录
→ 创建待激活企业成员
→ 成员首次授权登录
→ 创建或识别Link168主账号
→ 激活企业成员身份
→ 绑定Workspace和外部身份
```

同步阶段要求：

- 不直接批量创建已激活Link168用户。
- 待激活成员不获得企业数据访问权。
- 不自动产生个人会员、个人AI额度或个人名片。
- 企业管理员可查看待激活、已激活和异常数量。

首次授权要求：

- 校验平台授权、企业和成员归属。
- 已有Link168账号时复用原User ID。
- 没有账号时创建User ID和个人空间。
- 企业成员身份只激活一次，不重复占用席位。
- 激活过程记录来源、时间、Workspace和外部身份。

### P0-ENT-ID-3 离职与停用

**老板已批准。状态：待开发**

正式流程：

```text
检测成员离职或停用
→ 冻结企业访问权
→ 保留个人Link168账号
→ 企业客户、企业名片和工作记录继续归企业
→ 未完成客户和任务由管理员重新分配
```

要求：

- 离职成员立即失去原企业知识库、客户、AI额度和后台权限。
- 个人空间、个人会员和个人合法数据保留。
- 企业成员名片进入停用或归档状态。
- 未完成客户和任务进入待重新分配状态。
- 所有离职、冻结、恢复、解绑和重分配留痕。

### P0-ENT-ID-4 企业数据归属

**状态：待统一验证**

企业空间中的以下数据继续归企业：

- 企业主页
- 企业成员名片
- 企业客户和跟进记录
- 企业知识库
- 企业任务和工作记录
- 企业AI用量和分配记录

不得因成员离职转移到个人空间或直接删除。

## 6. 企业自购域名与协作平台

### 企业自购域名

- 企业负责购买、实名认证、备案、DNS和续费。
- Link168负责验证、绑定、HTTPS、状态检查、解绑和迁移。
- 企业版支持1个域名。
- 企业Pro支持多个域名。

### 企业协作平台第一阶段

建议范围：

- 企业授权
- 企业成员身份登录
- 部门与成员同步
- 待激活成员
- 离职冻结
- 新客户、待办和AI额度通知
- Link168工作入口

不包括聊天正文读取、复杂审批流、云文档双向同步、客户数据双向覆盖和跨平台群发。

首个实施平台尚待老板决定。

## 9. 企业角色页面

企业客户从“我的”进入企业空间：

- 管理员进入`/console/enterprise/admin`
- 普通成员进入`/console/enterprise/member`
- 多企业用户先选择企业空间

企业管理员权限等于企业成员基础权限加企业管理权限。

严格隔离对象是不同企业空间；企业内部按照角色和资源授权。

企业管理员页新增：

- 协作平台连接
- 组织同步状态
- 待激活成员
- 离职处理
- 客户与任务重新分配

## 12. 验收标准

### 微信与账号

- 微信可不填写邮箱直接注册。
- 同一微信重复登录不创建重复User。
- 已登录用户可以在“我的”绑定微信。
- 外部身份冲突不覆盖、不自动合并。
- 微信直接注册账号不因未绑定邮箱30天被冻结。
- 邮箱注册账号仍执行30天验证规则。

### 企业成员生命周期

- 通讯录同步只创建待激活成员。
- 待激活成员没有企业数据访问权。
- 首次授权正确复用或创建Link168主账号。
- 同一成员不会重复激活或重复占用席位。
- 离职后立即冻结企业访问权。
- 个人账号和个人空间保留。
- 企业客户、成员名片和工作记录继续归企业。
- 未完成客户和任务可由管理员重新分配。
- 全过程有审计记录。

### 产品闭环

- 手机底部只显示首页、名片、客户、AI、我的。
- 首页数据真实。
- 免费用户不能购买或调用付费AI。
- 不同企业无法互相访问数据。
- 支付、会员、AI、退款和佣金可追踪。
- 360–430px无横向溢出。
