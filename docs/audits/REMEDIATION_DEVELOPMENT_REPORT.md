## 4. 成本测算与不亏本保护

### 4.1 官方价格参考

2026-07-11核对阿里云百炼官方模型调用原价：

- `qwen3.7-plus`：每百万Token输入约¥2、输出约¥8。
- `qwen3.7-max`：每百万Token输入约¥12、输出约¥36。
- `qwen-turbo`：每百万Token输入约¥0.3、非思考输出约¥0.6、思考输出约¥3。

额度设计使用官方原价，不使用限时折扣、免费额度或新客优惠作为长期成本基础。

### 4.2 点数成本保护线

内部成本规则：

```text
每1,000 AI点对应的模型官方原价成本预算不高于¥1
```

对应模型成本压力上限：

| 套餐 | 售价 | 点数成本预算上限 |
|---|---:|---:|
| 轻量包 | ¥29.9 | ¥10 |
| 标准包 | ¥69 | ¥25 |
| 进阶包 | ¥149 | ¥60 |
| 专业包 | ¥299 | ¥130 |
| 旗舰包 | ¥599 | ¥280 |

标准文本任务按约120点估算。

以高成本的 `qwen3.7-max` 压力测试，4,000输入Token和2,000输出Token的官方原价成本约为：

```text
4,000 × ¥12 / 1,000,000
+ 2,000 × ¥36 / 1,000,000
= ¥0.12
```

120点对应¥0.12成本预算，因此标准任务口径能够覆盖较贵文本模型。使用Plus、Turbo、缓存或短输出时，实际成本通常更低。

### 4.3 保守利润压力测试

即使额外预留：

- 20%潜在推广佣金压力
- 4%支付与税费预算
- 8%基础设施、客服、风控和异常调用预算
- 点数对应的模型原价成本上限

五档仍保留约21%–35%的保守贡献空间。

当前AI加量包不参与推广返佣，实际安全边际高于上述压力测试。

这不是会计利润承诺。上线后必须按真实模型、Token、退款、支付手续费、税务和服务器成本每月复盘。模型原价上涨时，可调整新订单点数或扣点系数，但不得追溯减少已购买点数。

## 9. 验收要求

### AI加量包

- 免费用户前端和API均无法购买。
- Plus、Pro可完成个人包购买。
- 企业所有者或管理员可购买共享包，普通成员不能购买。
- 支付成功只入账一次。
- 每个批次准确生成90天到期时间。
- 多批次按最早到期优先扣减。
- 深度思考和高成本模型扣点高于普通文本任务。
- 调用失败回到原批次。
- 点数到期后不可继续使用。
- 页面、账本和服务端余额一致。

### 推广结算

- 支付后30天内不可提现。
- 退款订单不产生可提现佣金。
- 上月满足条件的佣金在次月15日进入结算。
- 可提现金额不足¥50时不能提现并自动累计。
- 已结算订单退款可生成负佣金或后续抵扣。
