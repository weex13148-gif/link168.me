## 1. 报告定位

本报告是 Link168 唯一持续更新的整改开发报告，用于记录：

- 老板已确认的产品决策
- 正式文档与代码之间的差距

本报告不是新的产品宪法，也不创造新的产品规则。发生冲突时，必须服从：

```text
老板最新明确决定
→ PRODUCT_CONSTITUTION.md
→ PRD.md
→ PROJECT_RULES.md
→ 本整改开发报告
→ 代码、数据库、页面与部署结果
```

以后不为每轮需求重复创建大量整改报告；新的正式需求、代码事实和验收结果统一增量更新到本文件。

## 2. 当前正式产品基准

### 2.1 五档正式套餐

| 套餐 | 月付 | 年付 |
|---|---:|---:|
| 免费版 | ¥0 | ¥0 |
| 会员 Plus | ¥69 | ¥599 |
| 会员 Pro | ¥139 | ¥999 |
| 企业版 | 不开放 | ¥8,800 |
| 企业 Pro | 不开放 | ¥19,800 |

正式规则：

- 不设创始用户价和永久低价。
- 企业多年订阅：2年95折、3年9折、5年8折、10年5折。
- 所有用户均可购买AI加量包。
- 免费版不赠送套餐内AI额度，也不默认获得六大AI Agent套餐权益。
- 免费版、Plus、Pro均可申请成为推广员，需管理员审核并支持邮件通知。
- Plus、Pro年付推广佣金为实际成交金额的20%。
- 企业订单佣金为10%–15%，长期合同单独核定。
- 企业版支持企业自购域名；企业 Pro 支持多个自购域名。

### 2.2 正式产品入口

- 用户控制台长期统一为 `/console/*`。
- 平台管理后台统一为 `/jeepwork`。
- 企业后台与Jeepwork严格分离。
- 旧 `/dashboard`、`/workbench/*` 只保留兼容迁移，不继续形成独立产品入口。

## 4. P0：规则与主闭环整改

### P0-1 五档套餐统一

**状态：** 【待开发】

整改目标：

- 将正式五档套餐写入唯一服务端配置。
- Plus支持¥69/月、¥599/年。
- Pro支持¥139/月、¥999/年。
- 企业版支持¥8,800/年和多年折扣。
- 企业 Pro支持¥19,800/年和多年折扣。
- `member_basic`、`member_plus`、`enterprise_pro_plus`等旧代码仅保留历史兼容，不进入新订单。
- `internal_test`不得出现在普通用户页面或正式订单中。

重点模块：

- `src/lib/billing/plans.ts`
- 套餐页面与首页价格展示
- 订单创建与金额快照
- 支付宝下单与回调校验
- Jeepwork套餐配置
- 服务端会员权益判断

验收要求：页面价格、订单金额、支付金额、会员生效和服务端权益完全一致。

### P0-2 AI加量包与免费用户准入

**状态：** 【待开发】

整改目标：

- 免费版不赠送套餐内AI额度。
- 所有用户均可购买AI加量包。
- 免费用户购买后，只能使用SKU明确授权的Agent、功能、额度和有效期。
- 购买AI加量包不自动升级会员，也不获得模板、数据、域名、去品牌或企业权益。
- 套餐额度、现金购买额度和企业共享额度分别记账。
- AI失败必须按原额度来源回补。

重点模块：

- AI准入服务
- AI额度账户与流水
- AI加量包SKU和订单
- AI Route Handler
- Jeepwork AI配置与用量管理

未决参数：

- ¥69、¥299、¥999分别包含的具体额度
- 加量包有效期
- 适用模型与Agent
- 退款和过期规则

### P0-3 统一用户控制台

**状态：** 【待开发】

整改目标：

- `/console`成为唯一用户入口。
- 建立 `/console/card`、`/console/products`、`/console/leads`、`/console/analytics`、`/console/ai`、`/console/knowledge`、`/console/membership`、`/console/account`。
- 旧路径保留兼容跳转，不直接删除现有可复用代码。
- 导航、登录回跳、支付回跳和错误返回统一到 `/console/*`。

### P0-4 平台后台隔离

**状态：** 【待开发】

整改目标：

- 普通用户导航不得展示Jeepwork。
- 只有具备平台角色的管理员可以进入 `/jeepwork`。
- 企业管理员不得进入Jeepwork。
- 管理操作必须记录审计日志。

### P0-5 去品牌权益

**状态：** 【待开发】

整改目标：

- 免费版显示Link168品牌。
- Plus执行品牌弱化。
- Pro及符合规则的企业套餐可隐藏品牌。
- 公开名片品牌展示由服务端权益决定，不能固定写死。

### P0-6 核心业务真实验收

**状态：** 【待验收】

必须真实验证：

1. 注册、登录、邮箱验证与30天冻结。
2. 创建、预览、发布经营名片。
3. 公开访问、点击、产品查看与真实留资。
4. 用户查看线索、修改状态和添加跟进记录。
5. 支付宝下单、回调、会员生效、续费和退款。
6. AI套餐额度、AI加量包、失败回补和权限拦截。
7. 360–430px移动端页面无横向溢出。

## 6. P2：企业能力

### P2-1 企业后台与租户隔离

**状态：** 【数据结构存在，业务闭环待开发】

- 企业管理员独立后台。

- 企业管理员不能访问平台级配置或其他企业。

### P2-2 企业订阅与合同

**状态：** 【待开发】

- 企业版默认5成员，超出¥699/人/年。
- 企业 Pro默认20成员，超出¥999/人/年。
- 多年订阅一次性付款，折扣不可叠加。
- AI额度按年度发放，未使用额度不跨年累计。
- 订单和合同保存价格、折扣、席位、权益和发票快照。

### P2-3 企业域名

**状态：** 【待开发】

- 企业版支持一个企业自购域名。
- 企业 Pro支持多个企业自购域名。
- 企业负责域名购买、实名认证、备案和DNS控制。
- 平台负责绑定验证、HTTPS、状态检测、解绑和迁移。

### P2-4 企业发票

**状态：** 【待开发】

- 按实际支付金额开票。
- 支持普通发票；专用发票按运营主体实际税务资格执行。

- 退款、红冲、开票金额和订单状态保持一致。

## 8. 后续更新机制

本对话后续采用以下机制：

1. 老板提出想法时，先区分“讨论意见”和“正式决定”。
2. 只有老板明确确认的规则才写入产品宪法或PRD。
3. 产品定位、核心用户、套餐结构、免费与AI根本边界等长期变化更新产品宪法。
4. 页面、价格、额度、席位、佣金、流程和验收标准更新PRD。
5. 每次正式更新同步维护 `DOCUMENT_INDEX.md` 版本与状态。
6. 代码差距、开发状态和验收结果统一更新本整改开发报告。
7. 文档更新直接提交到 `codex/link168-v2-direction`，不修改业务代码，除非老板另行明确要求开发。
