# Link168 比赛展示中心与 AI 客服展示页 PRD

**版本：** v1.0  
**日期：** 2026-07-12  
**状态：** 老板批准，等待独立开发批次  
**适用分支：** `codex/link168-v2-direction`  
**上位规则：** `PRODUCT_CONSTITUTION.md`、`PRD.md`、`PROJECT_RULES.md`、`PRD_MEDIA_UPLOAD_RULES.md`

> `/showcase` 是 Link168 面向比赛评委、投资人、政府/园区、合作伙伴的正式展示与尽调入口。必须保留，不得删除。部署时正常上传，但具体内容更新必须按本 PRD 独立开发、验收后再发布。

---

## 1. 一句话目标

把 `/showcase` 从“项目说明页”升级成可验证、可演示、可受控预览材料的正式比赛展示中心，并增加独立的 AI 客服展示页，让评委在 5–10 分钟内理解：

```text
Link168 是什么
→ 解决谁的问题
→ 产品已经做到什么
→ AI 客服如何工作
→ 访客如何转化为线索
→ 技术、安全、合规与商业模式是否可信
```

---

## 2. 现有能力与需要整改的事实

现有旧主线已经具备：

- `/showcase` 访问密码门禁。
- 评委、投资人、政府三种视角。
- 评委页的项目概览、五分钟体验、能力状态、技术摘要、AI 演示、进度、Q&A、证据和比赛资料区域。
- 访问 Session、展示开关和访问记录基础结构。

本轮必须整改：

1. “比赛资料下载”统一改为“比赛资料在线预览”。
2. 文件禁止提供公开原件地址、下载按钮或下载 API。
3. AI 演示状态不得硬编码为“可用”，必须来自真实配置和真实健康状态。
4. 没有真实数据时不得显示模拟经营数字。
5. 演示账号必须是独立受限账号，不得展示生产管理员账号。
6. 密码门禁、文件预览 API、AI 演示 API 必须使用同一受控 Session。
7. 旧 `master` 与 V2 主线实现差异必须先只读盘点，再增量迁移；不得整页覆盖 V2 新代码。

## 5. 比赛展示页必须具备的内容

### 5.1 项目首屏

必须明确：

```text
Link168（链接一路发）
面向个人创业者和小企业的 AI 商业主页
数字名片 + 产品服务展示 + AI 接待 + 客户线索 + 数据分析
```

首屏动作：

- 打开真实产品
- 开始五分钟体验
- 查看 AI 客服演示
- 在线查看比赛材料

### 5.2 问题与解决方案

只讲用户能理解的问题：

- 个人创业者和小企业资料分散。
- 客户扫码后不知道下一步做什么。
- 老板无法全天接待咨询。
- 访问、咨询和线索无法形成闭环。

对应解决：

```text
一个链接/二维码
→ 一个可装修商业主页
→ 一个 AI 接待窗口
→ 一套轻量客户线索与访问分析
```

### 5.3 五分钟体验路径

每一步必须包含：

- 操作入口
- 预计时长
- 验证目标
- 是否需要登录
- 当前状态：已完成 / 内测 / 规划
- 打开页面按钮
- 网络失败备用截图

建议路径：

1. 打开公开名片。
2. 查看身份、产品、服务和微信联系组件。
3. 询问 AI 客服产品或合作问题。
4. 查看 AI 推荐产品或联系方式。
5. 留下测试线索。
6. 进入受限演示后台查看线索与对话摘要。

### 5.4 核心闭环展示

必须展示完整链路，而不是孤立页面：

```text
创建名片
→ 添加组件
→ 发布公开页
→ 访客访问
→ AI 客服接待
→ 产品/服务推荐
→ 微信联系或留资
→ 后台生成客户
→ 数据统计与跟进
```

### 5.5 真实状态

能力统一分三类：

- 已完成
- 内测中
- 后续规划

禁止：

- 把设计稿写成已上线。
- 把静态页面写成真实 AI 调用。
- 把 API 占位写成已接通。
- 把零值冒充真实数据。
- 使用“即将上线”等内部语言污染普通产品页面。

展示中心可以说明规划，但必须清楚标注。

### 5.6 技术与安全

简明展示：

- Next.js、Prisma、PostgreSQL 模块化单体。
- 阿里百炼作为正式 AI 方向。
- 阿里云邮件推送、支付宝、国内服务器和数据库规划。
- Workspace 数据隔离。
- 文件上传安全、访问审计、内容举报和超级管理员治理。
- CI、类型检查、构建与移动端验收状态。

### 5.7 商业模式

展示正式五档：

- 免费版
- Plus
- Pro
- 企业版
- 企业 Pro

只展示已批准的价格和权益，不临时编造新的比赛专属套餐。

### 5.8 创始人与团队

建议包含：

- 创始人简介
- 创业经历
- 为什么做 Link168
- 当前一人公司 + AI Agent 协作方式
- 八个开发 Agent 的职责边界
- 当前真实阶段和下一步

不展示身份证、手机号、密钥、服务器地址等敏感资料。

### 6.2 支持文件

P0：

- PPT
- PPTX
- PDF
- PNG
- JPG/JPEG
- WebP

- DOC/DOCX
- MP4 演示视频

| 类型 | 最大文件 | 最大页数/时长 |
|---|---:|---:|
| PPT/PPTX | 50MB | 100 页 |
| PDF | 50MB | 150 页 |
| 图片 | 10MB | 单图 |
| MP4（P1） | 300MB | 20 分钟 |

最终限制需结合服务器、对象存储和转码能力配置，不在前端写死为唯一真相源。

### 6.3 上传入口

不新增普通用户一级导航。

建议入口：

```text

→ 展示内容
→ 比赛资料
→ 上传/管理
```

复用用户后台组件规则：

- 统一上传控件

- 统一媒体/素材库选择器
- 统一名称、说明、标签和排序
- 统一替换、删除、审计和垃圾回收
- 统一移动端适配

但权限不同：

- 只有 `super_admin` 或明确的 Showcase 编辑权限可上传、替换、发布和删除。

## 7. “文件禁止下载”的产品定义

### 7.1 能做到的边界

本产品中的“禁止下载”定义为：

- 不提供下载按钮。
- 不提供原文件公开 URL。
- 不提供原文件下载 API。
- 不返回 `Content-Disposition: attachment`。
- PPT/PPTX/PDF 原件只存储在私有空间。
- 前台只通过受控预览接口查看转换后的页面图像或受控流。
- 预览接口必须验证 Showcase Session。
- Session 失效后资源立即不可访问。
- 访问、翻页、失败和异常请求均可审计。

### 7.2 无法绝对阻止的行为

浏览器展示内容时，评委仍可能：

- 截图
- 录屏
- 使用开发者工具抓取已发送到浏览器的预览图
- 使用外部设备拍照

因此不得向用户承诺“技术上绝对无法复制”。产品目标是：

> 不提供原件下载、提高批量复制成本、保留访问证据和动态水印。

### 7.3 PPT/PDF 预览方案

推荐：

```text
原始 PPT/PPTX/PDF 私有上传
→ 病毒与格式检查
→ 服务端转换为逐页图片/安全预览格式
→ 生成低至中等清晰度预览
→ 动态叠加水印
→ 通过受控页面预览器逐页加载
```

禁止：

- 把原文件 URL 交给 Microsoft Office Online、Google Docs 或其他第三方在线预览。
- 在前端直接加载原始 PPT/PDF。
- 使用公开对象存储地址。
- 生成长期有效的原文件签名链接。

### 7.4 水印

预览页建议动态水印：

```text
Link168 比赛评审材料
仅供评审 · 禁止传播
访问会话尾号 / 时间
```

规则：

- 水印不遮挡核心阅读。
- 每页都存在。
- 不把完整 IP、手机号或姓名直接暴露在页面。
- 水印信息来自当前 Session，不写死在文件中。

### 7.5 浏览器限制

可以做但不能作为核心安全手段：

- 禁止右键菜单
- 禁止拖拽图片
- 禁止打印样式
- 禁止常规文本选择

真正安全边界必须依赖：

- 私有存储
- 服务端鉴权
- 受控转换
- 短时访问
- 限流
- 审计
- 水印

## 10. AI 客服展示页

### 10.1 页面目标

让评委清楚看到：

```text
访客提出问题
→ AI 识别咨询意图
→ 使用名片、产品、服务和 FAQ 回答
→ 推荐产品或微信联系方式
→ 识别高意向
→ 引导留资
→ 后台形成客户线索
→ 超出能力时转人工
```

### 10.2 页面路由

```text
/showcase/ai-customer-service
```

必须置于 ShowcaseGate 后，不公开索引。

### 10.3 页面布局

桌面端建议：

```text
左侧：公开 AI 名片手机预览
中间：AI 客服实时/静态演示对话
右侧：工作流、知识来源、状态和结果
```

移动端：

```text
场景选择
→ 名片预览
→ 对话演示
→ 本次结果
→ 后台证据
```

### 10.4 演示场景

第一批固定六个：

1. 产品介绍
2. 价格咨询
3. 合作咨询
4. 微信联系方式
5. 留下客户线索
6. 不知道时安全兜底/转人工

每个场景应提供 2–4 个推荐问题，减少现场输入成本。

### 10.5 演示模式

必须明确显示当前模式：

#### REAL

- 阿里百炼配置有效。
- 演示账号有额度。
- 服务健康检查通过。
- 使用受控演示知识和产品。
- 显示“真实 AI 演示”。

#### STATIC

- 使用预先审核的固定对话流程。
- 不调用模型。
- 显示“静态演示，不代表实时 AI 调用”。

#### OFFLINE

- AI 配置、网络或额度不可用。
- 显示真实原因和备用截图/录屏。
- 不伪装成功。

禁止把 `STATIC` 或 `OFFLINE` 显示成真实 AI。

### 10.6 AI 状态栏

展示：

- 模式：真实 / 静态 / 离线
- 服务状态
- 知识来源数量
- 产品数量
- 是否开启线索收集
- 是否开启转人工
- 本次会话是否产生测试线索

不展示：

- API Key
- 系统提示词全文
- 真实用户私密知识
- 其他 Workspace 数据
- 模型内部思维过程

### 10.7 对话区

必须支持：

- 欢迎语
- 推荐问题
- 用户问题
- AI 回复
- 回复来源提示
- 产品卡片
- 微信联系卡片
- 留资表单
- 转人工提示
- 停止、重试和错误状态

展示页使用专用测试身份和数据，不写入真实客户池。

若需要演示“生成线索”，写入单独演示域或标记：

```text
isDemo = true
source = showcase_ai_demo
```

演示数据不得进入真实经营报表、佣金、企业客户池或正式统计。

### 10.8 知识来源展示

只显示摘要：

- 名片基础资料
- 企业介绍
- 产品与服务
- FAQ
- 公开联系方式

可显示“本次回答使用了哪些类别”，但不暴露完整内部文档和提示词。

### 10.9 线索演示

演示流程：

```text
访客表达合作/报价意向
→ AI 请求称呼和联系方式
→ 用户填写测试信息
→ 显示“已生成演示线索”
→ 展示后台线索摘要卡
```

后台摘要：

- 测试访客
- 咨询主题
- 需求摘要
- 来源：AI 客服展示
- 意向等级
- 行为：产品查看/微信联系/留资
- 状态：演示数据

### 10.10 管理配置证据

展示当前用户后台已有配置能力的只读副本或截图：

- AI 接待开关
- 助手名称
- 欢迎语
- 语气风格
- 产品推荐
- 收集线索
- 允许举报
- 转人工
- 隐私提示

展示页不得直接修改生产配置。

## 11. AI 客服安全边界

- 只使用演示账号、演示名片和演示知识。
- 不调用其他用户或企业数据。
- 不允许模型自行承诺价格、合同、退款或服务效果。
- 未知问题必须明确无法确认。
- 联系方式只能来自已公开配置。
- 留资前展示隐私提示。
- 演示接口单 Session 限频、限轮次和限额度。
- 恶意内容、提示词注入和越权请求必须拒绝。
- AI 失败必须显示失败，不伪造回答。
- 免费用户正式产品不能因为展示页而获得真实 AI 权益。

## 12. 访问、隐私与审计

必须记录：

```text
showcase_session_success
showcase_session_failed
showcase_mode_open
showcase_material_open
showcase_material_page_view
showcase_ai_demo_start
showcase_ai_demo_question
showcase_ai_demo_lead_created
showcase_ai_demo_error
```

规则：

- 不记录访问密码明文。
- 不记录 AI 输入中的敏感字段全文，按安全规则脱敏。
- 日志用于安全和展示改进，不用于未经同意的营销。
- 超级管理员可查看聚合访问情况和异常请求。

- 权限与 Session 测试。

- 360/390/430px 浏览器测试。
- lint、typecheck、测试和生产构建。

## 15. 开发边界

本批不得顺带开发：

- 普通用户的公开文件网盘
- 任意用户上传 PPT 后公开分享
- 文档协同编辑
- 在线 Office 编辑器
- Canva 类海报/PPT 设计器
- 第三方 Office 在线预览
- 文件付费下载
- 微信登录、企业微信连接器
- 重型多 Agent 工作流平台
- 对外开放的通用 AI 客服试用平台
- 与 `/showcase` 无关的大规模数据库重构

不允许：

- 删除 `/showcase`。
- 把比赛展示改成普通用户入口。
- 把原件放到 `public/` 目录。
- 通过前端隐藏按钮代替服务端下载保护。
- 暴露真实密钥、生产管理员账号、数据库和服务器信息。
- 伪造 AI 成功、访问量、客户数或成交数据。

## 16. 验收标准

全部满足才算完成：

1. `/showcase`、评委、投资人、政府模式均受统一门禁保护。
2. 门禁错误尝试有限流，Session 过期后资料和 AI 同时失效。
3. 页面明确展示 Link168 的产品定位、闭环和真实状态。
4. 评委可在 5–10 分钟走完推荐体验路径。
5. 所有“比赛资料下载”文案和按钮已经移除。
6. PPT/PPTX/PDF 原件不具备公开 URL。
7. 未授权访问原文件和预览页返回 403/404。
8. 评委只能查看转换后的受控预览，并显示动态水印。
9. 页面不提供下载、打印或长期原件签名链接。
10. 文件转换失败不会覆盖已发布旧版本。
11. AI 客服展示页支持产品、价格、合作、微信、留资和兜底场景。
12. REAL / STATIC / OFFLINE 状态真实可区分。
13. AI 不可用时不伪造回复。
14. AI 演示只使用演示数据，不进入真实客户和经营统计。
15. AI 只能展示已公开联系方式和演示知识。
16. 演示账号为独立受限账号，不展示生产管理员凭证。
17. 没有真实数据时显示暂无数据，不显示模拟数字。
18. 360、390、430px 无横向溢出，PPT 翻页和 AI 对话可正常操作。
19. 访问、资料预览和 AI 演示均有安全审计。
20. lint、typecheck、相关测试和生产构建通过。

## 17. 与其他开发批次的关系

- 头像、产品图、图标选择器和基础素材库属于用户后台媒体能力。
- 比赛资料复用同一上传和素材底座，但使用独立 Showcase 权限和私有预览规则。
- AI 客服展示复用正式 AI 接待配置、产品、微信联系组件和线索结构，但演示数据必须隔离。
- 不与企业 AI 共享账本、企业完整 UI 等主线混在同一 Agent 批次。

建议单独安排一个 Showcase Agent 负责本 PRD，先报告现状和文件所有权，再进入开发。
