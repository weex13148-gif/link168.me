## 1. 产品一句话定位

**link168.me 是面向自媒体、小商家和一人公司的 AI 经营名片平台。**

用免费的二维码数字名片帮助用户承接流量，再通过财税、法务、市场调研、设计、社媒运营五大 AI Agent，帮助用户完成从展示、获客到经营的闭环。AI 能力通过白名单制内测逐步开放，普通用户默认不开放完整 AI 功能。

- 主 Slogan：**link168 — 一张二维码数字名片 + 五大 AI Agent，小商家低成本获客与经营**
- 辅助描述：**暖白、简洁、高级、可信的艺术商务风格**

## 2. 项目背景

小商家和自媒体面临三重困境：

1. **流量承接难**：在线下名片、海报、物料上只能留下一个链接，客人错过多个服务入口
2. **经营缺工具**：没有财税、法务、市场调研、设计、社媒运营的专业能力或预算
3. **经营数据分散**：平台散落在微信生态、小红书、抖音、店铺，缺少统一数据视角

同时，海外同类产品（如 Linktree）在中文体验、访问速度、合规能力上并不贴合中文用户需求。link168.me 的目标是成为中文环境下最自然、最可信的"**二维码数字名片 + 五大 AI Agent**"解决方案：

- 基础层：免费数字名片、链接聚合、二维码传播
- 增值层：五大 AI Agent（会员 / 企业版商业化方向）

## 3. 产品完整表达

link168.me 面向自媒体、小商家和一人公司。用户可以创建 `link168.me/用户名` 的公开主页，把微信客服、商品橱窗、课程目录、咨询入口、社群、公众号、小红书、抖音等入口集中展示，并通过二维码线下传播。

在此基础上，平台提供五大 AI Agent，帮助用户：

| AI Agent | 作用 |
|---------|------|
| 财税 AI Agent | 收入、成本、税费、经营资料辅助整理和经营提醒 |
| 法务 AI Agent | 合同风险初筛、协议条款解释、合规提醒和审阅清单生成 |
| 市场调研 AI Agent | 行业分析、竞品分析、城市市场判断、目标用户画像和推广建议 |
| 设计 AI Agent | 主页视觉建议、海报创意、商品宣传图、品牌风格和活动物料建议 |
| 社媒运营 AI Agent | 小红书、抖音、朋友圈、公众号内容选题、标题、脚本和发布计划 |

**⚠️ AI 结果仅供经营参考。** 财税 AI Agent 不替代专业税务意见。法务 AI Agent 不替代律师意见。市场调研 AI Agent 不保证商业结果。设计 AI Agent 仅作创意参考。社媒运营 AI Agent 输出需用户自行判断和修改。

## 4. 目标用户

| 用户类型 | 典型画像 | 核心诉求 |
|---------|---------|---------|
| 课程咨询者 / 知识付费博主 | 独立讲师、线下课老师 | 课程目录、咨询入口、往期学员案例，社媒内容助手 |
| 小商家 / 个体户 | 本地服务、手作品牌、淘宝/微店店主 | 商品橱窗、微信客服、经营数据提醒，设计与推广建议 |
| 内容创作者 | 公众号作者、小红书博主、视频创作者 | 各平台账号集中展示、粉丝聚合、选题与标题建议 |
| 社群运营者 / 一人公司 | 群主、活动组织者、自由职业者 | 活动列表、入群入口、联系方式，合规与法务风险提醒 |

## 5. 解决方案

1. **一个公开主页**：`link168.me/用户名`，任何人扫码/点击即可访问
2. **链接集中管理**：在一个后台里添加/编辑/排序所有入口
3. **二维码传播**：主页 URL 可生成二维码，印在名片/海报上
4. **可信视觉**：暖白、简洁、高级、艺术商务风格，中文友好
5. **举报与治理**：每个公开主页都可提交举报，平台管理员可查看与处理
6. **品牌 Footer**：免费版本的公开主页底部展示 `Powered by link168`，链接回首页

## 6. 核心用户流程

```
注册新用户 → 登录 → 创建/编辑个人主页 → 添加链接
                                 ↓
访问公开主页 ← 生成链接/二维码 ← 保存主页
    ↓
发现违规内容 → 举报中心提交 → 管理员后台处理
```

## 13. 管理员与举报合规设计

1. **举报入口**：所有公开主页均可通过 `/report` 或公开主页页面上的举报链接提交
2. **管理员后台**：通过 `/admin/reports` 查看举报列表与详情，受 `ADMIN_SECRET` 保护
3. **举报处理（规划功能）**：在超级管理员后台实现"待处理 → 已处理 / 已驳回 / 已封禁"等状态流转
4. **系统账号保护**：系统级账号（role=system）不可被普通管理员修改或重置密码
5. **权限分级**：user → admin → super_admin，权限边界见 `docs/SYSTEM_ACCOUNT_RULES.md`

## 14. 商业化路径

**内测版不涉及支付。** 当前阶段无支付实现。后续商业化路径建议按以下顺序规划：

1. **阶段一（MVP 验证期）**：免费使用，验证"是否有人真的创建主页并把它分享出去"
2. **阶段二（Pro 订阅）**：上线 Pro 会员，按月付费，解锁多主页、无品牌 Footer、高级主题、二维码自定义
3. **阶段三（商家/企业方案）**：团队协作、多成员管理、自定义域名、白标方案
4. **阶段四（生态）**：开放 API、模板市场、与第三方工具（公众号、小红书等）的轻量集成

## 15. 比赛阶段迭代方向

**产品优先，比赛第二。** 比赛材料必须服务真实上线，不为了比赛炫技而添加无用功能。

1. **初赛阶段**：完成 MVP 核心链路（注册 → 登录 → 主页 → 链接 → 举报 → 管理员查看），为 7月1日内测版打好基础
2. **复赛阶段**：打磨视觉系统（暖白、简洁、高级、艺术商务）、完善二维码生成与下载、接入真实邮件服务、补齐举报状态流转
3. **决赛阶段**：基于内测反馈持续迭代，完善 Pro 会员方案规划、数据统计规划，准备真实用户案例
