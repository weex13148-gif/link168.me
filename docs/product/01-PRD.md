## 1. 产品一句话定位

link168.me 是一个面向中文创作者、小商家、课程咨询者、社群运营者、个人 IP 和中小企业的**数字身份主页 + 二维码营销 + AI 助力成长工具**。用户可以创建 `link168.me/用户名` 的公开主页，把微信、商品、课程、咨询、社群、公众号、小红书、抖音等入口集中展示，并通过链接和二维码传播。AI 助力方向为产品长期规划，**内测版暂不开放**。

## 2. 项目背景

中文互联网存在多个内容与交易孤岛（微信生态、小红书、抖音、独立站点等），个人创作者和小商家常常需要在不同平台分别维护入口，在线下物料、名片、海报上只能留下其中一个链接。同时，海外同类产品（如 Linktree）在中文体验、访问速度、合规能力上并不贴合中国用户需求。link168.me 的目标是成为中文环境下最自然、最可信、最简单的"个人链接聚合主页 + 二维码营销"解决方案。

产品 Slogan：
- 主 Slogan：**link168 — 一个人，一个链接，连接全网**
- 辅助描述：**暖白、简洁、高级、可信、中文创作者友好的艺术商务风格**

## 3. 目标用户

| 用户类型 | 典型画像 | 核心诉求 |
|---------|---------|---------|
| 课程咨询者 | 独立讲师、知识付费博主、线下课老师 | 展示课程目录、咨询入口、往期学员案例 |
| 小商家 / 个体户 | 淘宝/微店店主、本地服务、手作品牌 | 集中展示商品、微信客服、下单链接 |
| 内容创作者 | 公众号作者、小红书博主、视频创作者 | 把各平台账号集中到一个主页，做粉丝聚合 |
| 社群运营者 | 群主、活动组织者、读书会 | 展示活动列表、入群入口、联系方式 |

## 4. 用户痛点

1. **多平台入口分散**：微信、小红书、抖音、店铺、课程页各有独立链接，物料放不下
2. **个人主页搭建成本高**：不会建站、没有域名、不会设计
3. **线下物料无法动态更新**：印出去的名片/海报上的链接不能改
4. **没有中文体验**：海外产品文案偏英文、访问慢、品牌不贴近中文用户审美
5. **合规/举报缺失**：主页内容被滥用时缺少举报与治理通道

## 5. 解决方案

1. **一个公开主页**：`link168.me/用户名`，任何人扫码/点击即可访问
2. **链接集中管理**：在一个后台里添加/编辑/排序所有入口
3. **二维码传播**：主页 URL 可生成二维码，印在名片/海报上
4. **可信视觉**：暖白、简洁、高级、艺术商务风格，中文友好
5. **举报与治理**：每个公开主页都可提交举报，平台管理员可查看与处理
6. **品牌 Footer**：免费版本的公开主页底部展示 `Powered by link168`，链接回首页

## 6. 核心用户流程

```
注册新用户 → 登录 → 创建/编辑个人主页 → 添加链接
                                 ↓
访问公开主页 ← 生成链接/二维码 ← 保存主页
    ↓
发现违规内容 → 举报中心提交 → 管理员后台处理
```

## 7. 内测版（2026-07-01 发布）定位与目标

link168.me **不是为了比赛而比赛的一次性 Demo，而是计划持续运营的真实产品。TRAE 创业比赛是阶段性加速器，产品真实上线和内测才是主线。

### 7.1 内测版一句话定位

> 面向中文创作者、小商家、课程咨询者、社群运营者、个人 IP 和中小企业的「数字身份主页 + 二维码营销 + AI 助力成长工具」。

### 7.2 内测版核心目标（内测用户可以完成的最小闭环）

1. 注册 / 登录
2. 创建个人主页
3. 编辑资料（用户名、显示名、简介、头像）
4. 添加 / 编辑 / 删除 / 排序链接
5. 通过 `link168.me/用户名` 公开访问主页
6. 复制主页链接用于分享
7. 生成主页二维码用于线下传播
8. 通过举报中心提交反馈

### 7.3 内测版不开放的能力（统一口径）

以下能力因成本、合规、复杂度原因，在 2026-07-01 内测版中明确暂不开放：

| 能力 | 当前状态 | 说明 |
|------|---------|------|
| 会员支付 / 真实支付接口 / 复杂会员体系 | 内测版暂不开放，后续版本规划 | 没有真实支付接口 |
| 企业 AI 完整功能 | 内测版暂不开放，后续版本规划 | 无真实 AI 接口，无完整业务闭环 |
| 超级管理员完整后台（冻结、封号、IP 查看） | 内测版暂不开放，后续版本规划 | 已规划，未实现 |
| 复杂数据统计（点击量、曝光量、转化率） | 内测版暂不开放，后续版本规划 | 无数据采集、无统计仪表盘 |
| 模板市场 | 内测版暂不开放，后续版本规划 | 只有默认主题 |
| 第三方登录（微信、手机号） | 内测版暂不开放，后续版本规划 | 仅支持邮箱登录注册 |

### 7.4 五大 AI 助力方向（长期规划，内测版暂不开放）

以下为产品长期商业化方向。**内测版暂不开放，后续版本规划**。当前没有真实 AI 接口，不对外宣称"已支持"。

| 方向 | 说明 |
|------|------|
| 1. AI 内容助理 | 帮助创作者生成主页介绍、链接标题、简介文案等 |
| 2. AI 设计助理 | 帮助用户生成主页视觉风格、二维码样式、配色方案 |
| 3. AI 运营助理 | 帮助用户分析主页数据、给出优化建议、做内容排版 |
| 4. AI 商业顾问 | 帮助小商家与课程咨询者做商品与课程方案、定价建议 |
| 5. AI 合规与资料助理 | 帮助用户自查主页内容是否合规、提供合规风险提示 |

### 7.5 内测版运营机制

- **发布方式**：邀请制注册
- **优先邀请用户**：小商家、课程咨询者、自媒体人、个人 IP 用户
- **内测期间核心收集**：bug、用户建议、主页使用反馈、真实转化场景观察
- **反馈收集渠道**：举报中心 / 反馈入口 / 邮件
- **内测用户上限**：根据服务器与团队运营资源决定

## 13. 管理员与举报合规设计

1. **举报入口**：所有公开主页均可通过 `/report` 或公开主页页面上的举报链接提交
2. **管理员后台**：通过 `/admin/reports` 查看举报列表与详情，受 `ADMIN_SECRET` 保护
3. **举报处理（规划功能）**：在超级管理员后台实现"待处理 → 已处理 / 已驳回 / 已封禁"等状态流转
4. **系统账号保护**：系统级账号（role=system）不可被普通管理员修改或重置密码
5. **权限分级**：user → admin → super_admin，权限边界见 `docs/SYSTEM_ACCOUNT_RULES.md`

## 14. 商业化路径

**内测版不涉及支付。** 当前阶段无支付实现。后续商业化路径建议按以下顺序规划：

1. **阶段一（MVP 验证期）**：免费使用，验证"是否有人真的创建主页并把它分享出去"
2. **阶段二（Pro 订阅）**：上线 Pro 会员，按月付费，解锁多主页、无品牌 Footer、高级主题、二维码自定义
3. **阶段三（商家/企业方案）**：团队协作、多成员管理、自定义域名、白标方案
4. **阶段四（生态）**：开放 API、模板市场、与第三方工具（公众号、小红书等）的轻量集成

## 15. 比赛阶段迭代方向

**产品优先，比赛第二。** 比赛材料必须服务真实上线，不为了比赛炫技而添加无用功能。

1. **初赛阶段**：完成 MVP 核心链路（注册 → 登录 → 主页 → 链接 → 举报 → 管理员查看），为 7月1日内测版打好基础
