## 上线前必须补齐的最小子集（Go-Live Must-Have）

即使我们不做会员和 AI，以下 4 件事也应当在正式面向用户前补齐：

1. **邮件发送链路**（忘记密码 / 邮箱验证的真实邮件发送）
2. **举报状态工作流**（待处理 → 已处理 / 已驳回）
3. **基本服务器备份**（PostgreSQL 备份脚本 + 定期执行）
4. **生产环境密钥管理原则落地**（`docs/tech/07-SECURITY_AND_KEYS.md` 所述原则实际执行）
