### 1.6 作品提交要求

报名帖要求：

- 发在 TRAE 官方社区报名专区。
- 标签必须从四个通用赛道中四选一；如参加公益附加赛题，可加选社会公益标签。
- 标题建议格式：报名赛道 + 创意名称。
- 正文不少于 100 字。
- 正文至少包含：创意名称 + 创意介绍、目标用户及痛点、价值与意义。
- 必须上传 TRAE Work 生成的创意产物 HTML 文件。
- 报名审核只看基础合规，不评创意好坏。
- 社区发帖成功不等于审核通过，需等待官方审核。

初赛帖要求：

- 初赛作品有效前提是报名审核已通过。
- 发在 TRAE 官方社区初赛专区。
- 标签需要与报名通过的赛道保持一致。
- 标题建议格式：报名赛道 + Demo 名称。
- 正文至少包含：Demo 简介、Demo 创作思路、Demo 体验地址、TRAE 实践过程。
- 最后附通过的社区报名帖链接。
- Demo 体验地址三选一：公开可访问体验链接；交互式 HTML 文件并用 Zip 上传社区；硬件赛道可用公开演示视频替代。
- TRAE 实践过程需清晰展示完整开发流程。
- 开发关键步骤截图不少于 3 张。
- 关键任务对话 Session ID 不少于 3 个。
- Session ID 可通过双击 TRAE 对话复制。

## 3. link168.me 赛道选择建议

### 3.1 推荐赛道

推荐主赛道：学习工作。

理由：

- link168.me 当前统一定位为“面向自媒体、小商家和一人公司的 AI 经营名片平台”。
- 核心价值不是娱乐，而是帮助小商户提升获客、经营、内容生产、财税/法务/市场/设计/社媒运营效率。
- 五大 AI Agent 面向实际工作任务：财税辅助整理、合同风险初筛、市场调研、设计建议、社媒运营内容生成。
- 数字名片、二维码、链接聚合是工作流入口；AI Agent 是经营效率工具。

备选赛道：社会服务。

只有当材料重点改成“帮助普通小微商户普惠使用 AI、降低创业门槛、促进就业与本地商业服务”时，才考虑社会服务。但从当前产品完成度和评审理解成本看，学习工作更稳。

不建议：

- 生活娱乐：会弱化商业经营主线。
- 硬件交互：link168.me 当前不是硬件产品。

### 3.2 当前最适合的比赛定位

一句话：

> link168.me 是面向自媒体、小商家和一人公司的 AI 经营名片平台，用免费的二维码数字名片承接流量，再通过财税、法务、市场调研、设计、社媒运营五大 AI Agent，帮助用户完成从展示、获客到经营的闭环。

评委能听懂的表达：

- 前台：每个用户拥有 `link168.me/用户名` 公开主页，把微信客服、商品橱窗、课程目录、社群入口、公众号、小红书、抖音等入口集中展示。
- 传播：用二维码把数字名片放到名片、海报、社群、朋友圈和线下物料。
- 后台：用户在 Dashboard 管理资料、链接、头像、公开主页。
- 增值：五大 AI Agent 帮小商家处理经营中的高频任务。
- 治理：提供举报中心、管理员后台、系统账号保护、安全与密钥管理规划。

### 3.3 为什么比普通链接聚合工具更适合参赛

普通链接聚合工具解决“把链接放在一起”。

link168.me 的比赛故事是：

1. 先用免费二维码数字名片承接分散流量。
2. 再用五大 AI Agent 帮小商户做经营任务。
3. 用超级管理员配置中心管理 AI 开关、白名单、额度、密钥脱敏。
4. 用举报中心和后台治理能力增强可信度。
5. 从“展示入口”延伸到“获客 + 经营 + 合规 + 商业化”的闭环。
