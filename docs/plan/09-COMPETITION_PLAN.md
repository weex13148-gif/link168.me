## 1. 参赛项目定位

link168.me 是面向自媒体、小商家和一人公司的 **AI 经营名片平台**。用户可以创建 `link168.me/用户名` 的公开主页，把微信客服、商品橱窗、课程目录、社群入口、公众号、小红书、抖音等集中展示，并通过二维码线下传播。在此基础上，平台提供五大 AI Agent（财税、法务、市场调研、设计、社媒运营），帮助用户完成从展示、获客到经营的闭环。一句话：

> **一张二维码数字名片 + 五大 AI Agent，帮助小商家低成本获客与经营。**

- 目标用户：自媒体 / 小商家 / 个体户 / 一人公司 / 内容创作者 / 私域运营者
- 视觉风格：暖白、简洁、高级、可信、中文用户友好的艺术商务风格
- 官方域名：`https://link168.me`
- 发布计划：**2026 年 7 月 1 日发布 v0.1 内测版（邀请制 + 白名单 AI 测试）**
- 五大 AI Agent：财税 AI Agent / 法务 AI Agent / 市场调研 AI Agent / 设计 AI Agent / 社媒运营 AI Agent（**7月1日内测版采用白名单测试，普通用户默认不开放完整 AI 能力，AI 结果仅供经营参考**）

## 4. 3 分钟 Demo 路线

1. **0:00-0:20 问题切入**（开场）
   - 痛点：创作者和小商家在名片上、海报上、公众号里，只能留一个链接，但他们有微信、小红书、抖音、店铺、课程页……
   - 屏幕：多平台入口截图 / 对比图
2. **0:20-1:30 产品演示**（核心）
   - 打开首页 → 点击注册（或登录预先创建的演示账号）
   - 进入 Dashboard → 填写用户名、显示名、简介、头像
   - 添加 3-5 条链接（微信、店铺、课程、小红书、抖音）
   - 保存后访问 `/用户名` 公开主页 → 点击链接验证跳转
   - 演示二维码：展示公开主页二维码，手机扫码访问
3. **1:30-2:10 合规与治理**（信任背书）
   - 打开举报中心 → 演示举报提交流程
   - 打开管理员后台 → 展示举报列表、举报详情（受 `ADMIN_SECRET` 保护）
   - 强调：密码 bcrypt 存储、HttpOnly Cookie、权限分级
4. **2:10-2:45 技术与架构**（技术深度）
   - 1-2 张架构图：Next.js + Prisma + PostgreSQL + 自建 Session
   - 说明部署原则：阿里云 ECS、HTTPS 域名、不自动部署
5. **2:45-3:00 总结与路线**（收尾）
   - 一句话总结：一个人，一个链接，连接全网
   - MVP 路线：注册→建主页→加链接→分享；未来：Pro 会员、模板、数据统计
   - 屏幕：停在公开主页截图 + `Powered by link168` Footer

## 5. 比赛亮点

### 5.1 产品亮点
- **对中文用户友好**：面向中文创作者、小商家的文案、视觉、交互
- **一个链接聚合全网**：微信/店铺/课程/小红书/抖音等入口集中展示
- **二维码营销闭环**：公开主页 URL 可扫码，支持线下物料
- **暖白、简洁、高级、艺术商务视觉**：区别于海外产品的"英文 + 卡片"风
- **可信品牌 Footer**：免费版必须展示 `Powered by link168`，增强品牌背书

### 5.2 技术亮点
- **Next.js App Router**：SSR/SSG 可演进，页面路由结构清晰
- **Prisma + PostgreSQL**：Schema 驱动，类型安全，迁移可追溯
- **自建 Session 鉴权**：HttpOnly Cookie + bcrypt 密码哈希 + LoginAttempt 反撞库
- **完整 API 路由矩阵**：认证、Dashboard、链接、举报、管理员，覆盖 MVP 全流程
- **权限分级**：user / admin / super_admin，系统账号保护（isSystem）

### 5.3 治理与合规亮点
- **举报中心与管理员后台**：基础治理能力已落地
- **密钥管理原则**：不入库、不 commit、最小权限、可轮换
- **审计与日志规划**：IP 记录、留存期、脱敏策略（规划文档已就位）

## 17. 评委可能问的 10 个问题与回答

> 提示：以下回答为参考稿，正式路演时请结合自己语气与演示节奏调整。

**Q1：你们和 Linktree、同类链接聚合产品有什么区别？**
A：区别有三点：第一是**中文体验**——视觉、文案、交互对中文创作者更友好；第二是**二维码与线下场景**——我们天然支持把链接变成二维码印在物料上，这对小商家和课程咨询者非常重要；第三是**合规与治理**——我们提供举报中心和管理员后台，对内容滥用有基本治理能力。

**Q2：你们的商业模式是什么？目前有收入吗？**
A：当前阶段没有真实收入，MVP 全部免费。未来商业化路径是：免费版（带品牌 Footer、有限链接）→ Pro 会员（可去除品牌 Footer、更多链接、主题、二维码自定义、数据统计）→ 商家/企业方案（团队协作、自定义域名、白标）。

**Q3：数据统计做到什么程度？会不会有隐私问题？**
A：目前**没有完整的数据统计系统**，比赛材料中所有"统计"字样都标注为规划功能。未来即使采集数据，也只会采集点击发生的时间、链接 id、匿名化来源，不采集个人信息，并遵循最小化原则。

**Q4：你们如何防范恶意用户把违规内容放进公开主页？**
A：MVP 已实现**举报中心**和**管理员后台**。任何公开主页都可以通过举报入口提交举报，管理员可以查看举报详情。后续超级管理员 PRD 已规划冻结主页、封禁账号等治理能力（已写 `docs/SUPER_ADMIN_PRD.md`）。

**Q5：密码与登录安全怎么做的？**
A：用户密码使用 **bcrypt 哈希** 存储，数据库不存明文。登录后使用 **HttpOnly Cookie + Session Token** 管理登录态，服务器记录登录尝试，可防止撞库和暴力破解。

**Q6：管理员权限分级是怎样的？**
A：系统中有 user / admin / super_admin 三级角色，另外还有 isSystem 系统账号，普通管理员不可修改或重置系统账号。详细规则见 `docs/SYSTEM_ACCOUNT_RULES.md`。

**Q7：企业 AI / 五大 AI Agent 功能做到什么程度？**
A：五大 AI Agent（财税、法务、市场调研、设计、社媒运营）是产品完成态与比赛主线。**7月1日内测版采用白名单制开放 AI Agent 测试，普通用户默认不开放完整 AI 能力。** AI 结果仅供经营参考，不替代专业税务意见、不替代律师意见、不保证商业结果。超级管理员配置中心统一管理 AI 服务的白名单和调用额度。

**Q8：上线后的服务器部署策略是什么？**
A：当前策略：**优先阿里云 ECS，不使用 Vercel 等海外服务作为主力**，使用 HTTPS 域名，Cookie Secure 在 HTTPS 环境下开启。重要原则：**禁止自动部署，任何线上改动必须由老板确认**。

**Q9：线上版本和本地代码一致吗？**
A：线上版本还未部署本地最近几次由 TRAE 参与的改动，所以比赛演示以本地 `npm run dev` 为准。

**Q10：赛后下一阶段你会做什么？**
A：赛后我会按顺序做五件事：① 补齐邮件发送链路；② 打磨公开主页的视觉与移动端体验；③ 完善二维码生成与下载；④ 完善举报治理工作流；⑤ 在真实创作者/商家中邀请试用，收集反馈并验证 Pro 会员需求。

**Q11（新增）：你们的产品是为比赛做的一次性 Demo，还是真的要上线？**
A：**产品优先，比赛第二。** link168.me 不是为了比赛而比赛的一次性 Demo，而是计划持续运营的真实产品。**2026 年 7 月 1 日我们将发布 v0.1 内测版（邀请制）**，面向中文创作者、小商家、个人 IP 用户真实上线。TRAE 创业比赛是我们的阶段性加速器，真实上线和内测才是主线。

**Q12（新增）：内测版哪些人可以用？需要付费吗？**
A：内测阶段采用邀请制，优先邀请小商家、课程咨询者、自媒体人、个人 IP 用户试用。**内测版免费使用，不涉及支付。** 会员与支付属于后续版本规划。

**Q13（新增）：线上现在就能用吗？还是要等 7 月 1 日？**
A：**当前线上版本不等于 7 月 1 日内测版。** 线上目前是历史版本，本地最新的 Trae 改动尚未部署。**7 月 1 日前会有一次由老板确认后的手动部署**，发布内测版。在那之前，比赛演示以本地 `npm run dev` 环境为准。
