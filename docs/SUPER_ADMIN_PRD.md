# Link168 超级管理员后台 PRD

## 1. 超级后台目标

超级管理员后台用于平台风控、违法违规处理、用户与内容安全管理，以及在依法合规前提下配合监管和调查。第一阶段只做权限与数据方案预留，后续再开发完整页面。

## 2. 用户管理

- 查看用户基础信息：账号、注册时间、角色、主页状态。
- 支持按邮箱、主页后缀、用户 ID、状态搜索。
- 支持将用户角色设置为 user、admin、super_admin。
- 普通管理员不得修改超级管理员权限。

## 3. 公开主页与链接查看

- 查看用户公开主页资料：头像、昵称、简介、公开地址、主页状态。
- 查看用户链接列表：标题、URL、状态、创建时间、更新时间。
- 支持按违规风险、举报次数、链接状态筛选。

## 4. 链接每日点击率

- 展示每条链接的每日点击量、曝光量、点击率。
- 支持按 7 天、30 天、90 天查看趋势。
- 用于识别异常传播、欺诈跳转和黑灰产风险。

## 5. 冻结用户

- 超级管理员可冻结用户账号或公开主页。
- 冻结后用户不可继续发布或展示风险内容。
- 冻结操作必须记录操作人、原因、时间和备注。

## 6. 封号用户

- 超级管理员可封禁严重违规账号。
- 封禁前应保留关键证据：主页快照、链接快照、举报记录、访问日志。
- 封禁状态应区别于临时冻结。

## 7. 冻结时间设置

- 支持设置冻结时长：1 天、3 天、7 天、30 天、永久。
- 到期后可自动恢复，也可由超级管理员手动恢复。
- 延长冻结或提前解冻都必须写入操作日志。

## 8. 访问者 IP

- 访问公开主页、点击链接、提交举报等行为应记录访问者 IP。
- 普通用户不可查看完整 IP。
- 超级管理员可在风控场景下查看完整 IP。

## 9. 登录者 IP

- 用户登录成功、登录失败、管理员登录均应记录 IP。
- 登录 IP 用于识别撞库、异常地区登录和账号被盗风险。

## 10. IP 记录留存

- 详细 IP 建议留存 90 天。
- 安全审计日志不少于 6 个月。
- 超过留存期后，IP 应脱敏或删除，仅保留地区级统计。

## 11. 普通用户只看地区分析

- 普通用户数据页只展示省市、设备、来源等聚合信息。
- 普通用户不得查看访问者完整 IP、登录者完整 IP。

## 12. 普通管理员不能看 IP

- 普通管理员可以处理举报、查看内容状态。
- 普通管理员默认不能查看完整 IP。
- 如需查看，应升级为超级管理员权限并记录授权原因。

## 13. 超级管理员才能看 IP

- 完整 IP 只对 super_admin 开放。
- 每次查看 IP 都必须记录：查看人、查看时间、查看对象、查看原因。

## 14. 搜索用户日志、访问日志、登录日志

- 支持搜索用户操作日志。
- 支持搜索公开主页访问日志。
- 支持搜索登录日志。
- 支持按用户、IP、时间、事件类型、风险状态过滤。

## 15. 合规目标

超级后台的核心目标是用于平台风控、违法违规处理、黑灰产识别、账号安全管理，以及依法配合调查。所有敏感数据查看都应最小权限、可审计、可追溯。
