# Link168 仓库版本管理规则

更新日期：2026-07-02

## 唯一正式版本

- 默认分支：`master`
- 本地同步来源：`origin/master`
- 服务器部署来源：`master`
- 生产回滚依据：服务器快照、发布包和明确记录的 `master` 提交 SHA

除非老板明确批准，禁止从任何 `ci/*`、`audit/*`、`release/*`、`showcase-*`、`competition-*`、`dashboard-*` 或其他历史功能分支直接部署。

## 当前正式基线

当前正式基线以 GitHub `master` 最新提交为准。2026-07-02 已统一以下核心规则：

- 免费版无限链接
- 五档会员方案
- 当前仅开放支付宝
- 新版用户后台作为正式 `/dashboard`
- 付费会员获得真实 AI 调用权限

## 历史分支说明

历史 PR 和临时分支主要用于：

- GitHub Actions 自动检查
- 比赛页面验收
- 内测包构建
- 支付与会员回归验证
- UI 与用户后台重构
- 安全和上线准备审计

这些分支不是独立产品版本，也不是生产部署来源。已关闭 PR 继续保留，作为审计和开发记录。

## 分支清理规则

可以删除：

- 已关闭且未合并的纯 CI 标记分支
- 已经合并到 `master` 的功能分支
- 已废弃的旧内测打包分支
- 已结束的审计和临时展示分支

必须保留：

- `master`
- 尚未完成且仍有明确负责人和任务的开发分支
- 尚未合并且仍需恢复代码的功能分支

删除分支前必须确认：

1. 对应 PR 已关闭或已合并；
2. 分支没有 `master` 中不存在、且仍需保留的业务代码；
3. 不包含生产密钥或唯一发布产物；
4. 已记录最后提交 SHA。

## 发布纪律

每次发布必须记录：

- GitHub `master` 提交 SHA
- Prisma 校验结果
- TypeScript 结果
- Next.js 生产构建结果
- 实际部署时间
- 服务器快照或备份位置
- PM2 进程状态
- Nginx 状态
- 浏览器手工验收结果

任何历史分支、旧压缩包或本地旧目录均不得替代上述正式基线。
