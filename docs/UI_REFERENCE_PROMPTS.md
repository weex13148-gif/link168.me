## 2. 命名与品牌一致性检查

- 当前源码展示文案以 `Link168` / `link168.me` 为主。
- 当前源码未发现页面展示文案直接使用 `Link1688`、`link1688`、`VLink` 或 `vlink.cc`。
- `README.md`、`PROJECT_RULES.md` 中出现 `VLink`，语境是“仅作为功能布局参考”，不是页面展示文案。
- 未跟踪历史资料文件名中存在 `Link1688_*`，本次不处理，因为它们不参与页面展示。
- 建议后续统一大小写：域名展示优先使用 `link168.me`，品牌名使用 `Link168`，避免 `Link168.me` 与 `link168.me` 混排。

## 3. 全局设计约束

- 产品气质：艺术感 + 商业感 + 中文自媒体审美。
- 目标用户：微信公众号、小红书、抖音、自媒体人、商家、个人 IP、知识博主、本地生活服务者。
- 首页 Hero 标题必须显著大于下方模块标题。
- 字体层级必须有差异：Hero、模块标题、卡片标题、正文、辅助说明、表单标签不能同号同重。
- 手机 mockup 必须统一比例，建议接近 `390:844`，不可拉伸。
- 图标必须统一尺寸：导航 18px，普通功能 22-24px，卡片主图标 28-32px，数据图标 24px。
- 不要绿色和白色随意混搭，绿色用于品牌点缀，金色用于 CTA/会员，白色/暖白用于阅读。
- 不要做成金融后台、程序员管理面板、廉价模板站、纯英文伪国际化页面。

## 4. 通用 Negative Prompt

适用于所有方案：

> 不要出现 VLink、vlink.cc、Link1688；不要英文假洋气大标题；不要密集金融后台；不要过度荧光绿；不要大面积高饱和金色；不要博彩感、资金盘感；不要廉价模板站；不要所有字体一样大；不要手机 mockup 拉伸变形；不要杂乱图标尺寸；不要低清晰度、模糊、乱码、错别字；不要复杂 3D 玻璃拟物；不要过多装饰元素遮挡表单；不要把二维码做成无法识别的装饰图。

# 5. 推荐排序

## A. 最适合 link168.me 第一版上线的 3 套方案

1. **方案 1：象牙青绿艺术商务**  
   最符合“艺术感 + 商业感 + 中文自媒体审美”的轻 SaaS 定位。既可信又好卖，适合覆盖自媒体、商家、个人 IP 的最大公约数。

2. **方案 9：极简白银专业顾问**  
   可读性、可信度、转化路径最稳，适合上线前减少视觉风险。缺点是记忆点略弱，可加入少量熊猫品牌符号增强识别。

3. **方案 3：小红书创作者暖调**  
   更贴近小红书、抖音创作者审美，适合女性用户和生活方式内容。建议作为局部主题或第二套风格。

## B. 最不建议采用的 2 套方案

1. **方案 4：高级黑金会员**  
   适合会员弹窗和高级主题展示，不适合作为全站默认。暗色 + 金色容易被误判为博彩/资金盘风，需要非常克制。

2. **方案 10：活力橙青增长营销**  
   转化感强，但长期作为默认风格容易显得营销过重，可能降低工具型产品的可信度。

## C. 原因

- 第一版上线最重要的是“可信、清楚、好卖”，不是炫技。
- link168.me 面向中文用户和自媒体人，首页必须能一眼理解“一个链接连接全网”，注册页必须能一眼理解“抢占 link168.me/后缀”。
- 方案 1 的青绿 + 暖白更适合长期使用，也能承接二维码、公开主页、举报中心、管理员后台等严肃页面。
- 方案 4 和 10 都有强风格，但风险也高：一个容易显得灰黑高压，一个容易显得促销廉价，建议作为会员主题或活动页，而不是主视觉。
