# 决赛现场演示流程

## 主演示路线（建议 8–10 分钟）

### 0:00–0:40 开场

- 一句话说明 Link168 是什么。
- 指出目标用户：中文创作者、小商家和一人公司。
- 说明演示将直接进入真实产品，不使用截图冒充功能。

### 0:40–1:40 用户问题

- 入口分散。
- 传统名片无法持续更新。
- 小团队缺少数字化和经营能力。

### 1:40–4:30 真实产品闭环

1. 打开产品首页。
2. 注册或使用固定演示账号登录。
3. 展示邮箱验证状态。
4. 设置头像、名称、简介和真实用户名。
5. 添加两个真实链接。
6. 保存并打开公开主页。
7. 点击按钮，确认直接跳转原始网址。
8. 展示二维码和手机预览。

### 4:30–5:30 后台与治理

- 打开超级管理员后台。
- 展示用户、邮箱验证、举报、冻结、日志和系统配置。
- 进入比赛中心，展示共享密码、文件管理和访问记录。

### 5:30–6:40 AI 与企业能力

- 说明五个比赛演示 Agent 的定位。
- 只在后台开关和真实配置可用时进行 AI 演示。
- 明确销售顾问、正式支付和客户线索属于下一阶段。

### 6:40–7:40 商业模式与差异

- 免费版承担获客入口。
- 会员版 188 元/年。
- 企业版提供资料库、AI 助理和团队服务。
- 与 Linktree、二维码工具和普通电子名片对比。

### 7:40–8:30 进展与结尾

- 已完成、内测中、下一阶段分开说明。
- 展示比赛资料下载区。
- 给出下一阶段目标和联系方式。

## 演示账号准备

- 准备一个固定普通用户演示账号。
- 准备一个固定超级管理员账号。
- 两个账号均提前登录并确认密码有效。
- 演示用户提前设置头像、简介和两个真实链接。
- 不在 PPT、录屏或公开资料中暴露真实密码。

## 故障备用方案

### 邮件服务异常

- 使用已验证的固定演示账号继续演示。
- 展示后台 SMTP 配置和历史成功记录。
- 不在现场反复修改真实 SMTP 密码。

### AI 服务异常

- 明确说明外部服务暂不可用。
- 继续展示核心主页闭环和 AI 架构边界。
- 使用提前录制的 AI 演示视频作为备用，不伪装为实时调用。

### 网络异常

- 使用本地录屏和关键截图。
- 打开离线 PPT/PDF。
- 准备手机热点，但不在台上临时修改服务器配置。

### 服务器异常

- 使用决赛演示视频完成产品闭环展示。
- 展示 GitHub 构建通过记录和关键功能截图。
- 记录问题，赛后再处理，不在台上执行危险命令。

## 上台前 30 分钟

1. 检查展示地址与共享密码。
2. 检查普通用户和管理员账号。
3. 检查 PPT、PDF、视频和离线备份。
4. 检查投屏比例、声音、浏览器缩放和网络。
5. 关闭无关通知、聊天窗口和密钥页面。
6. 预打开所有演示标签页，按顺序排列。
