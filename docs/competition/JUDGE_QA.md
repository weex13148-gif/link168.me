# 评委常见问题与回答要点

## 1. Link168 解决什么问题？

解决个人和小团队的线上入口分散问题。用户可以用一个公开主页集中展示内容、服务、联系方式和二维码，并在后台持续更新。

## 2. 为什么用户不直接使用 Linktree？

Linktree 主要面向海外链接聚合场景。Link168 更关注中文平台、微信传播、二维码、邮箱验证、后台治理、企业资料和后续 AI 经营能力。

## 3. 和普通电子名片有什么区别？

普通电子名片偏静态展示。Link168 提供真实公开地址、持续编辑、链接管理、二维码分享、邮箱验证、举报治理、管理员日志和可扩展会员能力。

## 4. 当前真正完成了什么？

注册登录、邮箱验证、找回密码、主页资料、真实用户名、头像、链接管理、公开主页、原始网址跳转、二维码、举报和超级管理员后台已经形成闭环。

## 5. AI 是否已经正式商用？

没有把内测能力描述成正式商用。五个比赛演示 Agent 处于内测或配置验证阶段；免费用户不会产生真实 AI 调用；销售顾问 Agent 属于下一阶段。

## 6. AI 为什么是优势？

AI 不是独立聊天框，而是计划建立在统一企业资料库和经营上下文之上。不同 Agent 使用各自提示词、模板和权限，但共享资料底座。

## 7. 商业模式是什么？

免费版降低使用门槛并形成用户入口；会员版 188 元/年提供高级主题、访问数据和高级二维码；企业版提供资料库、AI 助理、团队服务和更高额度。

## 8. 为什么用户愿意付费？

付费价值不是“多几个链接”，而是更专业的品牌展示、数据、二维码、企业资料和 AI 辅助能力。最终需通过内测用户和真实转化继续验证。

## 9. 现在有多少用户和收入？

只使用后台真实数据回答。没有真实用户或收入时，直接说明项目仍在内测，不使用假数字。

## 10. 技术架构是什么？

Next.js、TypeScript、Prisma、PostgreSQL、Node.js、PM2 和 Nginx。AI 配置、SMTP、权限、日志和文件下载均由服务端处理。

## 11. 如何保护 API Key 和用户数据？

API Key 不发送到浏览器；后台密钥加密或掩码展示；比赛文件保存在非 public 目录；管理员权限、访问日志、冻结和封禁能力由服务端校验。

## 12. 邮箱验证码为什么重要？

它减少虚假账号，支持找回密码，并为未来会员、企业服务和重要操作提供基础身份校验。

## 13. 项目最大的风险是什么？

风险包括获客成本、用户付费意愿、AI 调用成本、产品范围过大和单人团队执行压力。当前策略是先保证核心主页闭环稳定，再逐步开放付费与 AI。

## 14. 为什么一个人可以做这个项目？

项目使用 AI 辅助开发、设计、测试和内容整理，但关键业务规则、上线边界、数据安全和最终决策由项目负责人控制。

## 15. 下一阶段最重要的目标是什么？

完成真实用户内测、正式支付、访问数据、会员权益和企业资料闭环，并验证用户是否愿意为长期经营能力付费。

## 回答原则

- 先给结论，再给证据。
- 不夸大用户数、收入、AI 能力和完成度。
- 不公开密码、密钥、数据库信息和服务器细节。
- 不确定的数据明确说“目前没有可靠数据”。
- 每个回答尽量在 30–60 秒内结束。
