# 决赛文件清单

## 必需文件

| 文件 | 建议格式 | 内容要求 | 后台用途 |
|---|---|---|---|
| 决赛路演 PPT | PPTX + PDF | 8–12 分钟版本；定位、痛点、方案、产品演示、商业模式、竞争优势、项目进展、下一步 | `competition_ppt` |
| 项目说明书 | PDF | 2–6 页；项目背景、目标用户、核心闭环、技术架构、商业模式、当前边界 | `project_pdf` |
| 产品演示视频 | MP4 | 3–5 分钟；注册、邮箱验证、编辑主页、公开主页、链接跳转、二维码、后台 | `demo_video` |
| 产品关键截图 | PNG / JPG / WEBP | 首页、Dashboard、公开主页、邮箱验证、比赛中心、超级管理员后台 | `product_screenshot` |
| 评委体验说明 | PDF / DOCX | 展示地址、访问密码、演示账号、推荐顺序、已完成/内测/规划说明 | `judge_doc` |
| 评委问答清单 | PDF / DOCX | 用户价值、竞品、技术、商业化、合规、安全、AI 成本、计划 | `judge_doc` |
| 离线备份包 | ZIP | 上述全部文件及应急截图、录屏、演示说明 | `backup` |

## 建议文件

| 文件 | 建议格式 | 内容要求 | 后台用途 |
|---|---|---|---|
| 主体与合规资料 | PDF / 图片 | 营业执照、ICP备案、用户协议、隐私政策、举报入口、公司主体说明 | `judge_doc` |
| 开发与代码证明 | PDF / 图片 | GitHub 提交、TRAE 使用记录、构建通过记录、验收截图 | `judge_doc` |

## 文件命名建议

- `Link168_决赛路演_最终版_YYYYMMDD.pptx`
- `Link168_项目说明书_最终版_YYYYMMDD.pdf`
- `Link168_产品演示_最终版_YYYYMMDD.mp4`
- `Link168_评委体验说明_YYYYMMDD.pdf`
- `Link168_评委问答_YYYYMMDD.pdf`
- `Link168_决赛资料备份_YYYYMMDD.zip`

## 保存要求

每份最终文件至少保留三份：

1. 本地电脑正式目录。
2. 云盘或对象存储。
3. U 盘或移动硬盘离线备份。

上传到比赛中心后，应填写文件说明，并把最新 PPT 或 PDF 设置为主文件。旧版可以保留，但必须清楚标注日期和版本。
