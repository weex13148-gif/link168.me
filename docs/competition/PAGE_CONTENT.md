# 比赛展示页与路演内容口径

## 一句话定位

Link168 是面向中文创作者、小商家和一人公司的个人数字名片平台，用一个公开主页集中展示内容、服务、联系方式和二维码，并逐步扩展会员、企业资料和 AI 助理能力。

## 目标用户

- 内容创作者、自媒体账号主。
- 顾问、自由职业者和个人服务者。
- 个体商家、小团队和一人公司。

## 用户痛点

1. 内容、服务和联系方式散落在多个平台。
2. 传统名片无法持续更新，也不能承接线上传播。
3. 小团队缺少设计、运营、法务和财税能力。
4. 用户需要一个真实、可分享、可长期经营的统一入口。

## 核心解决方案

1. 注册并验证邮箱。
2. 设置真实用户名、头像、名称和简介。
3. 添加内容平台、网站、服务和联系方式。
4. 保存后生成真实公开主页。
5. 通过公开链接和二维码分享。
6. 在后台持续编辑、预览和管理。
7. 按会员和企业场景逐步扩展数据与 AI 能力。

## 当前真实能力

### 已完成

- 注册、登录、邮箱验证码、忘记密码和重置密码。
- 主页资料、真实用户名、头像、链接管理和实时预览。
- 公开主页、原始网址跳转和二维码分享。
- 举报、冻结、封禁、访问日志和系统配置后台。
- 比赛展示密码、比赛内容、文件管理、评委下载和访问记录。

### 内测中

- 企业 AI 工作台。
- 财税、法务、市场调研、设计和社媒运营比赛演示 Agent。
- 企业资料、访问分析和部分高级主题能力。

### 下一阶段

- 销售顾问 Agent。
- 正式会员支付。
- 客户线索、跟进和经营自动化。

## 商业模式

- 免费版：公开主页、基础链接和二维码分享。
- 会员版：188 元/年，高级主题、访问数据和高级二维码。
- 企业版：联系开通，企业资料库、AI 助理、团队服务和更高使用额度。

## 竞争差异

- 比 Linktree 更贴近中文平台、微信和线下二维码场景。
- 比静态二维码工具更强调长期更新和公开主页。
- 比普通电子名片增加后台治理、邮箱验证和可扩展 AI 架构。
- 核心主页闭环不依赖 AI，外部 AI 服务未开启时产品仍能使用。

## 安全与合规

- 免费用户不产生真实 AI 调用。
- API Key 只保存在服务端，不发送到浏览器。
- 比赛页面默认关闭，通过共享密码访问。
- 比赛文件保存在受保护目录，通过权限 API 下载。
- 首页保留用户协议、隐私政策、举报入口和真实备案信息。

## 结尾表达

Link168 不是为了把链接堆在一个页面，而是先让个人和小团队拥有一个真实、可分享、可持续经营的数字入口，再逐步接入数据和 AI 能力。
