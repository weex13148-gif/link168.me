# Link168 决赛资料总目录

本目录是 Link168 比赛资料的唯一文字来源。正式提交前，应以这里的清单与 `/jeepwork/competition-center` 后台状态为准。

## 页面与入口

- 评委展示页：`/showcase`
- 超级管理员比赛中心：`/jeepwork/competition-center`
- 比赛文件管理：比赛中心 → 文件管理
- 真实产品首页：`/`
- 用户后台：`/dashboard`
- 企业 AI：`/enterprise-ai`

## 文件

1. `FILES_MANIFEST.md`：需要准备、上传和备份的全部文件。
2. `PAGE_CONTENT.md`：比赛展示页与路演 PPT 的统一内容口径。
3. `DEMO_RUNBOOK.md`：现场演示顺序、主方案与故障备用方案。
4. `JUDGE_QA.md`：评委常见问题与回答要点。
5. `FINAL_CHECKLIST.md`：提交与上台前的最终检查。

## 真实性规则

- 能打开并操作的功能才写“已完成”。
- 需要真实配置或仍在验证的功能写“内测中”。
- 尚未完成的功能写“下一阶段”或“暂未开放”。
- 不使用假用户、假访问数据、假备案号、假订单和假 AI 调用。
- 比赛页面不在普通首页提供入口，只通过直接地址和超级管理员后台访问。
