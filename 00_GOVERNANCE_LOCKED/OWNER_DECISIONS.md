# Link168 老板决策登记

## 当前生效的最高决策

1. Link168 是面向个人创业者和小微企业的 AI 商业主页。
2. 核心能力是数字名片、业务展示、AI 接待、客户线索和访问分析。
3. 核心闭环是：展示业务 → 接待访客 → 收集线索 → 查看分析 → 跟进商机。
4. 产品宪法高于 PRD，PRD 高于临时任务提示词。
5. 任何 Agent 不得自行改变产品定位、定价、会员权益、核心用户流程或架构方向。
6. 删除页面、路由、字段、接口、未来付费能力或企业能力前，必须取得老板明确批准。
7. 未完成能力应隐藏、禁用或安全降级，不得伪造成功。
8. 普通用户后台固定为：首页、名片、客户、AI、我的。
9. 当前保持模块化单体，不引入无必要的微服务、Kubernetes 或 Kafka。
10. 生产服务器、数据库、密钥和外部系统不属于普通开发 Agent 的授权范围。

## 登记规则

新增重大决定必须记录日期、决定内容、影响范围和老板批准证据。普通 Agent 无权修改本文件。
