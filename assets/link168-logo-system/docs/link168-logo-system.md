# Link168 Logo System

状态：已确认的第 3 版视觉方向，2026-08-09。

## 品牌口径

- 主品牌名：`Link168`
- 中文品牌寓意：`链接一路发`
- 产品形态：网站型 App / 个人商业主页入口
- 品牌增长场景：免费用户公开分享页中的可点击 Link168 入口
- 公司全称不出现在 Logo 中；`link168.me` 不写入 Logo 主体

## 视觉逻辑

图形由三个层次组成：

1. 开放的圆角门户：表示一个个人商业主页或数字入口。
2. 蓝色垂直界面：表示页面、内容和可进入的数字空间。
3. 暖金路径：表示从入口出发，持续连接、触达和向前发展。

Logo 不使用链条、钱币、红包、博彩符号、盾牌或锁。暖金只做少量重点，不承担“发财图标”的直译。

## 使用规则

- 中文实际文案必须写成 `链接一路发`，不要在源文案中加入空格或改写成其他版本。
- Full lockup 在网页中建议不小于 160px 宽；独立图标建议不小于 20px。
- 图标四周至少保留图标宽度的 1/4 作为安全空间。
- 彩色版用于品牌主场景；单色版用于打印、协议、极端背景和无障碍降级。
- 分享页入口的按钮文案属于引流组件，不属于 Logo 本体。实际代码中应让 CTA 按钮或整个入口容器可点击，不能只把 SVG 当作交互按钮。
- SVG 中的英文采用系统无衬线字体栈，中文采用系统中文无衬线字体栈；若需要完全固定字形，应在设计软件中将字标转为路径后再替换对应 SVG。

## 当前限制

这些 SVG 是可直接用于 Web 的矢量基础版，图形、颜色、文案和尺寸已经固定；字标仍采用 SVG `<text>`，因此不同操作系统的字体渲染可能略有差异。提交商标、印刷或长期品牌资产前，应由设计人员确认最终字体授权并输出转路径版本。
