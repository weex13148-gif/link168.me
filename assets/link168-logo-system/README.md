# Link168 Logo System

这是 Link168 的第一版可复用 Logo 资产包，基于已确认的“蓝色主品牌＋少量暖金＋门户入口＋链接一路发”方向制作。

## 直接使用

```html
<img src="/brand/link168-logo-light.svg" alt="Link168｜链接一路发" />
```

深色背景使用 `link168-logo-dark.svg`，控制台顶部使用 `link168-logo-nav.svg`，favicon 或移动端使用 `link168-app-icon.svg`。

详细规则见 [`docs/link168-logo-system.md`](docs/link168-logo-system.md)。

## 重要说明

`link168-share-entry.svg` 是公开分享页品牌入口的视觉参考。实际网站实现时，入口必须使用真实的链接或按钮，不能把一张 SVG 图片误当成可交互元素。
