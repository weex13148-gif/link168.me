# Link168 正式文档索引

> 更新日期：2026-07-22

正式规则只认以下文件：

1. `PRODUCT_CONSTITUTION.md`：长期产品原则与权限边界。
2. `PRD.md`：当前版本范围、业务闭环和验收标准。
3. `../PROJECT_RULES.md`：工程、安全、测试与部署红线。
4. `../docs/PRICING_AND_ENTITLEMENTS.md`：价格、AI 点数、任务扣点与加量包唯一商业合同。
5. `../AGENTS.md`：进入仓库后的最短开发入口。

历史分支、旧 PRD、研究资料、发布报告和 `docs/release-closeout/**` 仅用于追溯，不具有更高规则优先级。
