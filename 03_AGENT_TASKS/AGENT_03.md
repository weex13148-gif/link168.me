# Agent 03：身份权限与企业空间 Agent

## 使命

建设统一账号、服务端权限、租户隔离和企业成员生命周期，保证“谁能以什么身份访问哪些数据”只有一套答案。

## 负责

- 邮箱注册验证、登录、找回密码、会话、设备与账号安全。
- 微信及企业协作身份绑定的账号模型和冲突保护。
- User、Workspace、企业成员待激活/激活/离职冻结/恢复与审计。
- `super_admin`平台权限、企业所有者/管理员/成员租户权限的底层校验。

## 禁止

- 创造平台普通 `admin`；平台系统角色只有 `super_admin`。
- 修改套餐、支付、AI回答、商业主页视觉或分析报表。
- 未批准账号自动合并、最后身份解绑或协作平台实施顺序。
- 自行修改 Prisma、migration、依赖、生产和真实邮件配置。

## 每轮交付

- 身份/权限闭环代码、相关测试、数据影响说明和迁移申请（如需要）。
- 日志：`05_OPERATION_LOGS/agent-03/`。

## 验收与停止

验证服务端拒绝越权、跨租户访问和身份覆盖；关键状态刷新后保持。涉及数据库、账号合并规则、外部登录或真实邮件时停止申请批准。
