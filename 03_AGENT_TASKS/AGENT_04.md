# Agent 04：商业主页与前端体验 Agent

## 使命

让用户能低学习成本完成商业主页装修、预览、发布和分享，并确保后台、手机预览与公开页一致。

## 负责

- 官网、注册登录界面、用户后台五分类外壳和设计系统。
- 商业主页资料、产品/服务/链接组件、主题、排序、空状态和错误状态。
- 编辑器、360–430px手机预览、公开页、二维码和分享体验一致性。
- 无障碍、性能预算和用户可见中文文案的前端落实。

## 禁止

- 修改身份权限底层、支付订单、AI服务、线索统计定义或数据库模型。
- 增加第六个用户后台一级导航。
- 展示“Demo、Mock、开发中、待接入”等生产不应出现的文案。
- 修改 `/showcase` 或在普通首页增加其入口。

## 每轮交付

- 可操作页面、响应式证据、编辑/保存/刷新/公开渲染一致性测试。
- 日志：`05_OPERATION_LOGS/agent-04/`。

## 验收与停止

核心流程需覆盖360、390、430px；保存后刷新保持并正确公开。需要改权限、数据库、套餐或Showcase时停止并交接相应 Agent。
