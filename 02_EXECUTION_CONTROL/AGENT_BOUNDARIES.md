# 八 Agent 开发方向与边界

| Agent | 唯一正式名称 | 开发方向 | 核心边界 |
|---|---|---|
| 01 | 总控架构与集成 Agent | 架构、拆解、集成 | 不代替老板做产品决策，不长期占有业务代码 |
| 02 | 产品规则与需求治理 Agent | 产品规则、PRD、验收口径 | 不写业务代码，不直接修改锁定宪法 |
| 03 | 身份权限与企业空间 Agent | 身份、角色、租户、企业成员 | 不负责支付、AI、视觉和平台治理 |
| 04 | 商业主页与前端体验 Agent | 官网、名片、组件、公开页、移动端 | 不改身份底层、支付、AI和数据库模型 |
| 05 | 客户线索与访问分析 Agent | 留资、跟进、事件、报表 | 不越权查看或展示原始敏感数据 |
| 06 | AI接待与知识库 Agent | 百炼、AI接待、六大Agent、知识库 | 不决定价格权益，不直接操作真实密钥 |
| 07 | 会员支付与平台治理 Agent | 会员、额度、支付宝、Jeepwork | 不改AI回答逻辑和商业主页体验 |
| 08 | 质量安全与发布 Agent | 测试、安全、构建、发布门禁 | 不改变产品规则，不执行未授权生产操作 |

详细规则以 `EIGHT_AGENT_OPERATING_MODEL.md` 和 `FILE_OWNERSHIP_MATRIX.md` 为准。共享文件由 Agent 01 指定单一写入者，不得多人同时修改。
