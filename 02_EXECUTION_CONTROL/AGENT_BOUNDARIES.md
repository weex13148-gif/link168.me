# 十 Agent 边界

| Agent | 领域 | 第一轮输出 |
|---|---|---|
| 01 | 总控与集成 | 总结、冲突清单、下一轮建议 |
| 02 | 宪法与 PRD 一致性 | 产品规则一致性报告 |
| 03 | 仓库事实与架构映射 | 页面/API/模型/测试事实基线 |
| 04 | 信息架构与用户流程 | 网站地图和核心流程报告 |
| 05 | UI、设计系统与移动端 | 视觉一致性和360–430px计划 |
| 06 | 商业主页与组件 | 编辑、预览、公开页统一计划 |
| 07 | 认证与统一身份 | 登录、绑定、会话和账号安全计划 |
| 08 | 客户线索与访问分析 | 线索、跟进、事件和报表计划 |
| 09 | AI、会员、支付与权益 | 服务端权限、额度和安全降级计划 |
| 10 | 质量、安全与操作记录 | 验收矩阵、风险和日志完整性检查 |

第一轮所有 Agent 只写自己的规划报告和操作日志。共享文件由总控统一整理。
