# 集成顺序

固定执行顺序：

1. 老板确认本轮目标和重大规则。
2. Agent 02 固化需求、状态与验收口径。
3. Agent 01 划分任务、精确文件和共享文件写入顺序。
4. Agent 03–07 在无重叠领域内并发开发；Agent 08并行准备独立测试。
5. Agent 01 集成共享文件和跨域接口。
6. Agent 08执行质量、安全、构建和发布门禁。
7. 涉及生产、外部系统或数据库时，再由老板批准下一步。

后续代码集成原则：

产品规则 → 身份与租户 → 领域服务 → 用户体验 → 商业化 → 集成 → 独立验收。

共享文件不得并发修改。总控只能在各领域报告齐全后确定真实开发顺序。
