# 当前轮范围：八 Agent 治理基线建立

## 唯一目标

在不修改业务代码的前提下，将十 Agent 临时规划结构收口为八 Agent 固定业务域结构，明确名称、职责、文件归属、并发限制、依赖顺序和验收门禁。

## 本轮允许

- 读取仓库代码和有效文档
- 在指定规划输出文件中记录事实、冲突和建议
- 在各自操作日志目录新增记录
- 运行不改变数据和外部状态的只读检查

## 本轮禁止

- 修改业务代码、数据库模型、迁移、依赖和配置
- 修改锁定治理区、正式 PRD和业务代码
- 操作服务器、数据库、GitHub 设置、密钥或外部服务
- 删除、移动或批量格式化现有文件
- 声称未验证能力已经完成

## 完成条件

八张正式任务卡、固定运行模型、文件所有权矩阵、集成顺序和验收标准一致；旧第九、第十任务卡完成归档。
