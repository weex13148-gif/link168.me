# 八 Agent 文件与领域所有权矩阵

本矩阵定义默认所有权。每轮任务仍必须列出精确文件；默认所有权不等于可以无限修改。

| Agent | 默认负责领域 | 不得自行进入的领域 |
|---|---|---|
| 01 | `02_EXECUTION_CONTROL/**`、`03_AGENT_TASKS/**`、集成清单与架构决策 | 业务功能、价格决策、生产环境 |
| 02 | `PRD.md`、`PROJECT_RULES.md`、`DOCUMENT_INDEX.md` 的授权维护及产品报告 | 业务代码、数据库、锁定宪法直接修改 |
| 03 | 认证、会话、账号安全、身份绑定、Workspace、企业成员和租户权限 | UI视觉、支付、AI业务、平台治理 |
| 04 | 官网、用户后台外壳、商业主页、编辑器、组件、主题、预览、公开渲染和移动端 | 身份底层、支付、AI服务、数据迁移 |
| 05 | 客户线索、跟进、访问事件、来源归因、分析报表和普通用户隐私展示 | 登录、会员支付、AI生成、平台后台 |
| 06 | AI接待、六大AI Agent、统一知识库、百炼适配、AI任务与调用安全 | 套餐定价、支付订单、基础身份、Showcase |
| 07 | 套餐、权益、额度账本、支付宝、订单退款、推广佣金、Jeepwork和平台超级管理员 | 商业主页UI、AI回答逻辑、企业成员身份底层 |
| 08 | `tests/**`、验收脚本、质量报告、安全检查和部署前只读核验 | 产品方向、业务规则重写、生产执行和未授权业务修复 |

## 共享高风险文件

以下文件或类别没有永久业务写入者，每轮由 Agent 01 指定唯一写入者：

- `prisma/schema.prisma` 与 `prisma/migrations/**`
- `package.json` 与全部锁文件
- 根布局、全局样式、全局中间件和应用级配置
- 通用身份/权限拦截器、公共API响应结构和跨域类型
- 套餐/权益的唯一常量来源
- CI、构建和部署配置
- `PRD.md`、`PROJECT_RULES.md`、`DOCUMENT_INDEX.md`

`00_GOVERNANCE_LOCKED/**` 不属于共享文件，而是全员禁写区。

## 冲突处理

发现所有权重叠时，相关 Agent 立即停止写入并提交：冲突文件、所需变更、业务原因、依赖顺序和风险。Agent 01 只能指定写入顺序；涉及产品规则、删除、价格、权益、数据库或生产时必须升级给老板。
